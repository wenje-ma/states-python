## 算法 1：判别底座训练（三模型 + 分层 5 折）

**输入**：$56$ 件有效已知样本（$14$ 成分 + 类型标签）。
**输出**：逻辑回归、随机森林、决策树三个判别模型及其分层 $5$ 折交叉验证准确率。

**流程**：
1. 分层 $5$ 折：每折用其余 $4$ 折训练、该折测试，分别评估：
   - 逻辑回归：管道「标准化 → 逻辑回归（最大迭代 $2000$）」；
   - 随机森林：$500$ 棵树；
   - 决策树：最大深度 $3$、叶节点最小样本数 $2$。
2. 记录三模型的折外准确率均值。
3. 全量样本上分别拟合最终模型：逻辑回归在标准化后的数据上拟合，随机森林与决策树在原始数据上拟合；保存标准化器与三模型供判别使用。

## 算法 2：风化还原模型重建（复用主线 A）

**输入**：采样点级有效成分表（含风化程度 $Y$）。
**输出**：高钾、铅钡各自的风化程度回归系数、反应比例、反推分母与 $R^2$。

**流程**：
1. 对高钾、铅钡分别处理：剔除关键成分子集存在缺失的采样点（关键成分子集同问题一算法 6：高钾 $\mathrm{SiO_2}$/$\mathrm{K_2O}$/$\mathrm{CaO}$/$\mathrm{Al_2O_3}$；铅钡 $\mathrm{SiO_2}$/$\mathrm{CaO}$/$\mathrm{Al_2O_3}$/$\mathrm{PbO}$/$\mathrm{P_2O_5}$）。
2. 风化程度赋值同问题一算法 5（未风化点/无风化 → $0$，严重风化点 → $1.0$，一般风化 → 高钾 $0.8$、铅钡 $0.75$）。
3. 以关键成分为解释变量、$Y$ 为响应变量做最小二乘回归，取系数。
4. 计算反应比例 $r_{d}=\frac{\Delta_{d}}{\Delta_{\mathrm{SiO_2}}}$：各成分（风化组均值 $-$ 未风化组均值）$\div$（风化组 $\mathrm{SiO_2}$ 均值 $-$ 未风化组 $\mathrm{SiO_2}$ 均值）。
5. 计算反推分母 $A=\beta_{\mathrm{SiO_2}}+\sum_{d\in\mathcal{S}\setminus\{\mathrm{SiO_2}\}}\beta_{d}r_{d}$：$\mathrm{SiO_2}$ 系数 $+$ 其余关键成分（系数 $\times$ 反应比例）之和。
6. 保存每类的系数、反应比例、反推分母、样本数与 $R^2$。

## 算法 3：假设-验证风化前成分还原

**输入**：某未知样本观测成分、假设类别（高钾或铅钡）、对应类型的风化还原模型。
**输出**：还原后的风化前成分向量；若假设不可行则返回「不可行」。

**流程**：
1. 可行性检查 1：该假设类型的关键成分子集必须全部检出且非 $0$，否则假设不可行。
2. 用假设类型的风化程度（高钾 $0.8$、铅钡 $0.75$）与反推分母计算 $\mathrm{SiO_2}$ 变化量：$\Delta_{\mathrm{SiO_2}}=$ 假设风化程度 $\div$ 反推分母。
3. 逐成分还原：预测风化前 $=$ 观测含量 $-$ 反应比例 $\times$ $\Delta_{\mathrm{SiO_2}}$；反应比例缺失的成分保留原观测值，观测缺失的成分置 $0$。
4. 可行性检查 2（物理范围）：任一分量小于 $-0.5$、大于 $100.5$，或总和大于 $105$，则还原结果超出成分含量物理范围，假设不可行。
5. 返回还原向量或「不可行」。

## 算法 4：三模型概率预测与多数表决

**输入**：某样本成分向量、判别底座（标准化器 + 三模型）。
**输出**：三模型的类别概率与各自投票、多数表决类别。

**流程**：
1. 逻辑回归：对标准化后的向量输出铅钡概率 $P_{\mathrm{lr}}$。
2. 随机森林：对原始向量输出铅钡概率 $P_{\mathrm{rf}}$。
3. 决策树：对原始向量输出铅钡概率 $P_{\mathrm{dt}}$。
4. 每模型按概率 $\ge$ $0.5$ 判铅钡、否则判高钾，形成三票。
5. 多数表决：三票中铅钡 $\ge$ $2$ 票判铅钡，否则判高钾。

## 算法 5：最终类别综合判定（自洽过滤 + 最大置信度）

**输入**：某未知样本的观测成分、表面风化状态、判别底座、风化还原模型。
**输出**：最终类别、最终依据、置信度（$=|P-0.5|\times2$）。

**流程**：
1. 直接判别：用观测成分经算法 4 得类别与 $P_{\mathrm{lr}}$，作为候选之一（依据「直接判别」）。
2. 若样本风化，对高钾、铅钡两种假设分别执行算法 3 还原：
   - 还原可行 → 将还原成分代入算法 4 判别，得到该假设下的判别类别与 $P_{\mathrm{lr}}$，加入候选（依据「<假设>假设还原(判为<类别>)」）；
   - 还原不可行（关键成分缺失或超出物理范围）→ 跳过该假设。
3. 自洽过滤：保留「判别类别与 $P_{\mathrm{lr}}$ 的朝向一致」的候选（即判铅钡者 $P_{\mathrm{lr}}>0.5$、判高钾者 $P_{\mathrm{lr}}\le0.5$）；若无自洽候选则退回全部候选。
4. 最终判定：在候选池中取 $|P_{\mathrm{lr}}-0.5|$ 最大者（置信度最高）作为最终类别与依据。
5. 记录直接判别 $P$（铅钡）、各假设还原 $P$（铅钡）、最终类型、置信度与判别依据。

## 算法 6：乘性高斯扰动翻转率检验

**输入**：某未知样本观测成分、判别底座、扰动幅度 $5\%$ 与 $10\%$、重复 $100$ 次。
**输出**：各幅度下的类别翻转率。

**流程**：
1. 基准判别：对原始观测成分经标准化后用逻辑回归输出铅钡概率，记其 $>0.5$ 与否为基准类别。
2. 对每个扰动幅度 $\delta\in\{5\%,10\%\}$，重复 $100$ 次：
   - 逐成分乘性扰动：含量 $\times$ 正态随机数（均值 $1$、标准差 $\delta$）；
   - 扰动后重新标准化并逻辑回归判别；
   - 若扰动后类别与基准类别不同，翻转计数加 $1$。
3. 翻转率 = 翻转次数 $\div$ $100$（对应论文 $f_{i}=\frac{1}{100}\sum_{m=1}^{100}\mathbb{1}\{\widehat{y}_{i}^{(m)}\neq\widehat{y}_{i}\}$）。
4. 全部样本翻转率为 $0$ 即判别结果对成分测量误差稳健。
