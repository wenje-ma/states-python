## 按论文顺序连起来讲（这才是能"顺下来"的讲法）

**一句话主线**：数据进来 → 洗干净 → 先搞清楚"风化跟谁有关"（5.1）→ "风化改变了什么成分"（5.2）→ "能把风化前算回来"（5.3）→ "两类玻璃靠什么分"（6.1）→ "类内还能怎么细分"（6.2）→ "分得稳不稳"（6.3）→ "把前面攒的模型用到 8 件未知样品上"（7.1→7.3）。

每步的**输出都是下一步的输入**，你按这个记就不会断：

### 第 0 步：预处理（一切的源头）

- **干什么**：筛（85%~105% 剔无效点）→ 分（缺失三档）→ 补（SVR 只补 K₂O/PbO/BaO）→ 并（多采样点聚合，56 件独立样本）→ 变（对数比变换）
- **产出三个口径，分别喂给三类下游**：
  - 保留 NaN 版 → 5.1/5.2 统计检验（检验自己处理缺失）
  - SVR 插补版 → 6.1/7.1 判别模型（模型要完整数值）
  - 对数比版 → 6.3 特征方案对比
- **连接点**："多口径"不是废话——每种方法对数据要求不同，预处理一次备齐，后面才不卡壳

### 5.1：风化跟谁相关？（决定后面的分组方式）

- **输入**：保留 NaN 版
- **方法**：卡方独立性检验（类型/纹饰/颜色 × 风化）→ 频数不足 → 蒙特卡洛置换 → Spearman/Kendall 定方向
- **产出**：风化只与类型显著相关 → **这个结论决定了后面所有分析只按类型分组**

### 5.2：风化具体改变了什么？（给 5.3 提供依据）

- **方法**：Mann-Whitney U（变没变）+ Cohen's d（变多大、什么方向）
- **产出**：高钾富硅、铅钡失硅 → 你知道"哪些成分在风化中起主导"，5.3 选关键成分就有依据

### 5.3：能把风化前算回来吗？（问题三的暗线！）

- **方法链**：赋风化程度 → 回归风化函数 → 反应比例 → 反推公式
- **产出**：高钾/铅钡各一套反推公式 `ŝ = x − r·Y/A`
- **★ 记住这个跨连接**：你以为 5.3 只是问题一的收尾，其实它是问题三风化样本还原的**工具**——7.1 的"假设-验证"全靠它

### 6.1：两类玻璃靠什么分？（问题二的入口，也是问题三的底座）

- **方法**：Spearman → RF 特征重要性（前 7 位 91.6%）→ 三判别模型 → 分层 5 折 CV
- **产出两样东西**：
  - 核心 7 成分 → **喂给 6.2 聚类**（降维）
  - 判别底座（LR/RF/DT）→ **原封不动搬去 7.1 判未知样品**
- 顺带产出：可读规则 PbO≤5.46

### 6.2：类内怎么再分？（吃 6.1 的产出）

- **输入**：6.1 的核心 7 成分
- **方法**：K-means++ → 轮廓系数/SSE 定 K → Ward 对照 → 命名
- **产出**：高钾 K=4、铅钡 K=6

### 6.3：分得稳不稳？（给 6.2 擦屁股）

- **方法**：±5%/±10% 扰动重聚类 + ARI、三套特征对比、K±1 敏感性
- **产出**：划分不是碰巧（高钾 ARI 0.981/0.939）

### 7.1~7.3：把攒下的模型用出去

- **输入**：6.1 的判别底座 + 5.3 的反推公式 + 8 件未知样品
- **方法**：未风化直接判别；风化样本"假设-验证"（先假设类型 → 用对应反推公式还原 → 再判别 → 自洽才采纳）
- **结果**：A1/A6/A7 高钾，其余铅钡，置信度全 ≥0.72
- **收尾**：扰动 100 次翻转率全 0
