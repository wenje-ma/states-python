论文模型使用顺序 · 数据流链条

从上到下就是论文的建模顺序。每个环节：上一步给了什么 → 这里用什么方法 → 产出喂给下一步的谁。框内蓝字 = 产出。

0 预处理筛选 · 分级 · SVR插补 · 聚合 · 对数比变换
原始三张表 → 累加和 85%~105% 筛掉无效点 → 缺失三档分级 → 只补 K2O/PbO/BaO → 同文物多采样点聚合 → ALR/CLR 对数比变换
产出：三个数据口径 —— 保留NaN版（→5.1/5.2 统计检验）、SVR插补版（→6.1/7.1 判别模型）、对数比版（→6.3 特征对比）
↓
5.1 风化关联卡方独立性检验 + 蒙特卡洛置换 + Spearman/Kendall
检验"风化 × 类型/纹饰/颜色"是否独立；纹饰颜色频数不足 → 置换检验兜底；秩相关定关联方向
产出：风化只与类型显著相关（铅钡风化 70% vs 高钾 33%）→ 决定后面全按类型分组，不再看纹饰颜色
↓
5.2 风化差异Mann-Whitney U + Cohen's d
分类型比较风化/未风化各成分：U 检验看"变没变"，d 看"变多大、什么方向"
产出：高钾富硅、铅钡失硅（SiO₂ d=4.80 / −2.45）→ 支撑 5.3 选关键成分、讲出核心故事
↓
5.3 风化前还原风化程度回归 → 反应比例 → 反推公式
赋风化程度 Y → 回归风化函数 → 估计各成分相对 SiO₂ 的反应比例 r → 反推 ŝ=x−r·Y/A；标准化偏差验证 + 虚拟变量回归对照
产出：高钾/铅钡各一套反推公式 ★跨问题：这套公式是 7.1 风化样本还原的工具
↓
6.1 分类规律Spearman → RF特征重要性 → 三判别模型 → 分层5折CV
找哪些成分区分两类：RF 重要性取前 7 位（91.6%）；逻辑回归/随机森林/决策树三模型交叉构建；5 折 CV 报精度
产出：核心 7 成分 ★→6.2 聚类降维；判别底座三模型 ★→7.1 判别未知样品；规则 PbO≤5.46
↓
6.2 亚类划分K-means++ + 轮廓系数/SSE选K + Ward层次聚类对照
核心 7 成分标准化 → K-means++ 聚类；K 由轮廓系数最大+SSE肘部定；Ward 对照验证结构一致；按主导差异成分命名
产出：高钾 K=4（5/7/3/1件）、铅钡 K=6（15/9/8/3/3/2件）亚类划分
↓
6.3 稳健性乘性扰动 + ARI + 特征方案对比 + 类数敏感性
±5%/±10% 扰动重聚类 100 次用 ARI 度量；7/14/CLR 三套特征对比；K±1 重聚类
产出：划分稳健的证据（高钾 ARI 0.981/0.939、铅钡 0.790/0.759）
↓
7.1 判别方法判别底座 + 假设-验证还原
未风化样本直接判别；风化样本：假设高钾→用高钾反推公式还原→再判别；假设铅钡同样走一遍；自洽才采纳
产出：8 件样品的判别依据与置信度（逻辑回归 P 为主、三模型投票定案）
↓
7.2 判别结果A1/A6/A7 高钾 · A2/A3/A4/A5/A8 铅钡
置信度全部 ≥0.72；A6/A7 高钾假设自洽（0.97+）；A2/A5 两假设不可行退回直接判别；A8 与文献分歧用化学证据论证
产出：最终判别结论
↓
7.3 敏感性乘性扰动 + 类别翻转率
对 8 件样品成分施加 ±5%/±10% 扰动各 100 次，统计判别类别翻转率
产出：翻转率全为 0 → 判别结论稳健
★ 三个跨问题连接（答辩最出彩的地方）：① 5.3 的反推公式在 7.1 被风化样本还原复用；② 6.1 的判别底座原封不动搬到 7.1；③ 6.1 的核心 7 成分是 6.2 聚类的输入。整篇论文不是三个孤立问题，而是一条"预处理 → 机理分析 → 建模 → 应用"的流水线。
