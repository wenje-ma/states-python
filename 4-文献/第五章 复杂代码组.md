## 代码组与缩进

不同于其它大多数语言，Python 的代码组不能使用大括号 `{}` 来控制类、函数或者其他逻辑判断，其最具特色的就是用**缩进**来表示代码组。可以使用 tab 或空格键来表示缩进。缩进的空白数量是可变的，但**同一代码块的语句必须包含相同的缩进空白数量**。

```python
if True:
    print("True")
else:
    print("False")
```

缩进不一致会报错（IndentationError: unexpected indent 或 unindent does not match any outer indentation level）。例如 tab 和空格混用即使表面对齐也会报错。建议在每个缩进层次使用单个 tab 或两个空格或四个空格，不要混用。

缩进相同的一组语句构成一个代码块，称为**代码组**。像 `if`、`while`、`def` 和 `class` 这样的复合语句，首行以关键字开始，以冒号结束，该行之后的一行或多行代码构成代码组。首行及后面的代码组合成一个程序模块。

## 准备知识

### 标识符

- 由字母、数字以及下划线组成，区分大小写字母，不能以数字开头，不能使用空格，不能使用保留字；
- 以单下划线 `_` 开头：代表不能直接访问的类属性，不能通过 `from xxx import xxx` 导入；
- 以双下划线开头：代表类的私有成员；
- 以双下划线开头和结尾：特殊方法的专用标识，如 `__init__()` 代表类的构造函数。

### 分号与多行语句

使用分号可以在同一行显示多条语句：

```python
x = 'Why'; y = 'do you'; z = 'learn Python?';
print(x + y + z)   # Why do you learn Python?
```

使用斜杠 `\` 将一行的语句分为多行显示：

```python
vegetables = 'potato ' + \
    'tomato ' + \
    'cabbage'
# 'potato tomato cabbage'
```

语句中包含 `[]`、`{}` 或 `()` 括号就不需要使用多行连接符：

```python
WeekDays = ['Monday', 'Tuesday', 'Wednesday',
            'Thursday', 'Friday']
```

### 注释

- 单行注释以 `#` 开头；
- 多行注释一般使用三个单引号 `'''` 或三个双引号 `"""`；
- 三引号可以由多行组成，常用于文档字符串，在代码组中一般被当做注释；
- 函数之间或类的方法之间可以使用空行分隔；空行并不是 Python 语法的一部分，但便于代码维护或重构。

### 输入函数 input

`input([提示信息])` 接受一个标准输入数据，返回为 string 类型。执行后显示提示，用户在方框内输入，按回车键退出并返回输入内容。

```python
input("按下回车键退出，其他任意键显示输入的内容\n")
```

## 条件语句

```python
if 判断条件:
    执行语句
elif 判断条件:
    执行语句
else:
    执行语句
```

`else` 为可选语句。判断条件可以用 `>`、`<`、`==`、`>=`、`<=` 表示关系。

## 循环语句

循环语句允许执行一个语句或语句组多次。Python 提供两种循环：`while` 循环和 `for` 循环，可以构造嵌套循环。

### while 循环

当判断条件为真时循环处理执行语句；当判断条件为 False 时循环结束。基本形式：

```python
while 判断条件:
    执行语句
```

判断条件可以是任何表达式，任何非零、或非空的值均为 True。while 语句和 if、for 一样，无需使用 end 结束函数，用缩进表示语句是否属于同一程序模块。

**例 5.2.1**：

```python
number = 0
while (number < 3):
    print('The number is', number)
    number += 2
print('The number ends at', number)
# The number is 0
# The number is 2
# The number ends at 4
```

**例 5.2.2**（求和）：

```python
和 = 0
n = 0
while n <= 3:
    和 += n
    print(n, 和)
    n += 1
print(和)
```

## 函数

函数是组织好的、可重复使用的、用来实现单一或相关联功能的程序模块。Python 中有三类函数：内置函数、用户自定义的一般函数以及用户自定义的匿名函数。

### 内置函数

Python 内置了很多有用的函数，如 print()、abs()、int()、float()、str()、bool()、len()、range()、type() 等（课件中列出了一张较大的内置函数表）。

```python
abs(-20)          # 20
int('123')        # 123
float('12.34')    # 12.34
str(100)          # '100'
bool(1)           # True
bool('')          # False
```

函数名其实就是指向一个函数对象的引用，可以把函数名赋给一个变量（别名）：`a = abs; a(-1)  # 1`。

调用函数时参数数量不对会报 TypeError（如 abs() 能且仅能接受 1 个参数）；参数类型不对也会报 TypeError（如 abs('a') → bad operand type for abs(): 'str'）。可以用 `help(abs)` 查看帮助信息。

### 自定义函数

规则：

1. 函数代码块以 `def` 关键词开头，后接函数标识符名称和圆括号 `()`；
2. 参数放在圆括号中间；
3. 函数的第一行语句可以选择性地写一些函数说明（文档字符串）；
4. 函数内容以冒号起始，然后换行缩进；
5. `return` 表达式结束函数，选择性地返回一个值给调用方。不带表达式的 return 相当于返回 None。

```python
def functionname(parameters):
    "函数_文档字符串"
    function_suite
    return [expression]
```

**例 5.3.2（去除首尾空格）**：

```python
def trim(s):
    while s[0] == ' ':
        s = s[1:]
    while s[-1] == ' ':
        s = s[:-1]
    return s

str = ' Susan '
trim(str)     # 'Susan'
```

**例 5.3.3（字符串拼接）**：

```python
def plus(str1, str2):
    total = str1 + str2
    return total

plus('数据', '科学')      # '数据科学'
plus(str1 = '数据', str2 = '科学')   # '数据科学'（关键字参数可改变顺序）
```

### 参数类型

- **必备参数**：必须以正确的顺序传入函数，调用时的数量必须和声明时的一样；
- **关键字参数**：函数调用使用关键字参数来确定传入的参数值，允许调用时参数的顺序与声明时不一致；
- **默认参数**：调用函数时，缺省参数的值如果没有传入，则被认为是默认值：

```python
def plus(str1, str2 = 'science'):
    total = str1 + str2
    return total

plus('statistical')        # 'statistical science'
plus(str1 = 'statistical') # 'statistical science'
```

- **不定长参数**：声明时不会命名，加了星号 `*` 的变量名会存放所有未命名的变量参数：

```python
def 输出可变长度(arg1, *vartuple):
    print(arg1)
    print(vartuple)

输出可变长度(1)       # 1  ()
输出可变长度(1, 2, 3)  # 1  (2, 3)
```

### return

`return [表达式]` 退出函数，选择性地向调用方返回一个表达式；不带参数值的 return 返回 None。

**例 5.3.7（列表反转，三种写法）**：

```python
def 反转1(li):
    for i in range(0, int(len(li)/2)):
        temp = li[i]
        li[i] = li[-i-1]
        li[-i-1] = temp
    return li

def 反转2(list):
    for i in range(int(len(list)/2)):
        list[i], list[-i-1] = list[-i-1], list[i]
    return list

def 反转3(ListInput):
    RevList = []
    for i in range(len(ListInput)):
        RevList.append(ListInput.pop())
    return RevList

li = [1, 2, 3, 4, 5]
反转1(li)    # [5, 4, 3, 2, 1]
```

### 匿名函数 lambda

没有名字的函数称为匿名函数。创建匿名函数需要用到 `lambda`。lambda 的主体是一个表达式，而不是一个代码块，语句中只能有一个表达式，不用写 return，返回值就是该表达式的结果。lambda 函数不能访问自有参数列表之外或全局命名空间里的参数。

```python
lambda x: x * x
lambda x, y: x + y
```

**调用方式一：map 函数**。语法 `map(function, iterable, ...)`，将第一个参数（函数）作用到第二个参数（可迭代对象）上，返回一个迭代器，要用 list() 才能正确显示结果。

```python
map(lambda x: x * x, [1, 4, 9])   # <map object>
list(map(lambda x, y: x + y, [1,4,7], [2,5,8]))   # [3, 9, 15]
```

**调用方式二：把匿名函数赋值给变量**：

```python
square = lambda x: x * x
square(5)     # 25

sum = lambda x, y: x ** 2 + y ** 2
sum(1, 4)     # 17

summation = lambda x, y: x + y
summation(1, 2)   # 3

circle = lambda x, y: x * x + y * y
circle(3, 4)      # 25
```

**filter 函数**：用于过滤不符合条件的元素，返回符合条件的元素。语法 `filter(function, iterable)`：接收序列的每个元素作为参数传递给函数，结果可能为 True 或 False，最后仅仅返回取值为 True 的元素。Python3 中返回的是一个 filter 类，需要用 list 函数转为列表之后才能正确显示。

```python
def odd(n):
    return n % 2 == 1
list(filter(odd, range(1, 10)))                # [1, 3, 5, 7, 9]
list(filter(lambda x: x % 2 == 1, range(10)))  # [1, 3, 5, 7, 9]

import math
def sqrit(x):
    return math.sqrt(x) % 1 == 0
list(filter(sqrit, range(1, 10)))                            # [1, 4, 9]
list(filter(lambda x: math.sqrt(x) % 1 == 0, range(1, 10)))  # [1, 4, 9]
```

**list 函数**：将一个序列转换为一个列表（之前多次使用）。类似的还有 int()、str()、float()、tuple() 等类型转换函数，将数据的类型进行转换并返回一个新的对象。
