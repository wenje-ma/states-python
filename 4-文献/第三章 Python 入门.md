## 表达式与运算符

本节主要介绍 Python 基础表达式用法：加法 `+`、减法 `-`、乘法 `*`、除法 `/`、指数 `**`、向下取整 `//`、取余 `%`，以及运算的优先级规则。

### 基本运算

```python
4 + 5
4 - 5
4 * 5
```

### 乘方

乘方运算通过两个连续的 `*` 号表达，注意两个 `*` 号中间不能用空格。

```python
2 ** 3        # 8
3 ** 2        # 9
2 ** 0.5      # 1.4142135623730951
```

### 优先级

Python 表达式遵循熟悉的优先级规则：优先计算括号之内的表达式，之后是指数运算，然后计算乘除，最后再算加减。

```python
(1 + 3)**2          # 16
1 + 3**2            # 10
(2 + 1) * 4 ** 2 - 1
```

### 三种除法

**浮点除法 `/`**：

```python
4 / 5   # 0.8
4 / 2   # 2.0  （任何两个数相除，即使能整除，计算结果一定是浮点数）
```

- 在进行 `/` 运算时，除数不能为 0，否则会给出语法错误提示。

**向下取整 `//`**：即比商更小的整数值。如果商是正数，取整数位；如果商是带非零小数位的负数，取整数位减去 1 以后的结果；如果恰好被整除，返回一个整数值。

```python
9 // 3    # 3
5 // 2    # 2
5 // 3    # 1
5 // -3   # -2
-5 // 3   # -2
-5 // -3  # 1
```

注意：两个相连的除号之间也不能有空格。

**取余 `%`**：注意是向下整除之后的余数。

```python
5 % 2     # 1
5 % 3     # 2
5 % -3    # -1
-5 % 3    # 1
-5 % -3   # -2
```

**综合**：任何两个数字相除，计算结果总是浮点数。

```python
9 / 3         # 3.0
9 % 3         # 0
9 // 3        # 3
11 // 3 * 3 + 11 % 3   # 11
```

## 数值类型

本节主要介绍 Python 数值类型：`int`（整数）、`complex`（复数）和 `float`（浮点数），以及对应的数值精度。

### 整数 int

整数表示没有小数部分的整数，包括负数、零或者正数。Python 可以处理任意大小的整数，但整数不能以 0 开头。

```python
3
0
-786
```

### 浮点数 float

浮点数用小数点表示，总是带一个小数点。浮点数运算可能会有四舍五入的误差。

```python
0.0      # 0.0
5.       # 5.0
15.20    # 15.2
21.9     # 21.9
```

科学计数法格式为 `a e b`，其中 a、b 为数值，e 是符号：

```python
32.3e+18    # 3.23e+19
-32.54e100  # -3.254e+101
70.2E-12    # 7.02e-11
```

浮点数非常灵活，但有一些限制：

1. 浮点数可以表示很大或者很小的数字，但存在一定的范围限制（非常大的数字表示为 `inf`，非常小的数字表示为 0）：

```python
2e306          # 2e+306
2e306 * 10     # 2e+307
2e307 * 100    # inf
2e-322         # 2e-322
2e-322 / 10    # 2e-323
2e-322 / 100   # 0.0
```

2. 浮点数只能表示 15 位或者 16 位有效数字，剩下的精度就会丢失（在进行任何算术运算之前，额外的数字被丢弃）：

```python
0.6666666666666666 - 0.6666666666666666123456789   # -1.1102230246251565e-16
```

3. 浮点数在做算术运算之后，最后的几位数字常常可能不准确：

```python
2 ** 0.5                       # 1.4142135623730951
(2 ** 0.5) * (2 ** 0.5)        # 2.0000000000000004
(2 ** 0.5) * (2 ** 0.5) - 2    # 4.440892098500626e-16
```

上面的最终结果非常接近零，但不精确为零。这个问题几乎出现在所有的编程语言中，并不单单是 Python 的问题。

### 复数 complex

复数由实数部分和虚数部分构成，用 `a + bj` 或者 `complex(a,b)` 表示。

注意：
1. 可以使用 `j` 或者 `J` 来表示虚数，这两种方法等价；
2. 虚数 `j` 或 `J` 前面必须要有一个数值，不能单独使用。

```python
3.14j            # 3.14j
complex(0, 3.14) # 3.14j
2j               # 2j
5.j              # 5j
9.322e-36j       # 9.322e-36j
.876j            # 0.876j
-.6545+0J        # (-0.6545+0j)
3e+26J           # 3e+26j
4.53e-7j         # 4.53e-7j
complex(2, 5.)   # (2+5j)
```

## 字符串

本节主要介绍 Python 中的字符串数据类型及其相关字符串方法：连接 `+`、重复 `*`、索引 `[]`、格式化 `%` 等。

字符串可以使用半角状态下的单引号或双引号（`'` 或 `"`）创建。字符串既可以包含传统的数值型数据，也可以包括布尔值 True 或 False。表达式的含义取决于其结构和正在组合的值的类型。

```python
"data" + "science"        # 'datascience'（加法是字符串连接运算符）
"data" + " " + "science"  # 'data science'
'Data ' * 2               # 'Data Data'（星号是重复操作）
```

单引号和双引号都可以用来创建字符串：`'hi'` 和 `"hi"` 是相同的表达式。双引号通常是首选，因为它们允许在字符串中包含单引号。

```python
"This won't work with a single-quoted string!"
```

函数 `str()` 返回任何值的字符串表示形式：

```python
"That's " + str(1 + 1) + '."'   # "That's 2."
```

### 索引与切片

Python 使用方括号来截取字符串。从左到右，索引从 0 开始（0, 1, 2, …）；从右到左，索引从 -1 开始（-1, -2, -3, …）。

```python
'Hello'[0]       # 'H'
'Hello'[1]       # 'e'
'Hello'[-1]      # 'o'
'Hello'[0:2]     # 'He'
'Hello'[0:-2]    # 'Hel'
'Hello'[2:]      # 'llo'
'Hello'[:]       # 'Hello'
'Hello'[:-1]     # 'Hell'
```

### in / not in

用 `in` / `not in` 检验一个字符串是否整体包含在另一个字符串中：

```python
'Tom' in 'Tom and Jerry'       # True
'Jerry' in 'Tom and Jerry'     # True
'Spike' in 'Tom and Jerry'     # False
```

### 字符串方法

字符串方法，本质上就是操作字符串的函数，通过在字符串后面放置一个点来调用。

```python
"loud".upper()            # 'LOUD'（大写）
'statistics'.capitalize() # 'Statistics'（首字母大写）
'statistics'.center(12)   # 'statistics'（居中补齐到指定长度）
'statistics'.isalpha()    # True（至少一位字符且均为字母）
'hitchhiker'.replace('hi', 'ma')   # 'matchmaker'（替换所有子串）
```

字符串方法也可以使用变量名称调用：

```python
s = "train"
t = s.replace('t', 'ing')   # 'ingrain'，不改变字符串 s，s 仍是 "train"
u = t.replace('in', 'de')
u                           # 'degrade'
```

### 输入与输出

**input 函数**：执行后等待用户键盘输入，直至按下回车键后自动退出。

```python
input("按除回车键之外的其他任意键，显示输入的内容，直至按下回车键退出。")
```

**print 函数**：语法为 `print(*objects, sep='', end='\n', file=sys.stdout)`

- 第一个参数 objects：可以一次输出多个对象，输出多个对象时需要用分隔；
- 第二个参数 sep：用来间隔多个对象，默认值是一个空格；
- 第三个参数 end：用来设定以什么结尾，默认值是换行符 `\n`，可以换成其他字符串；
- 最后一个参数 file：表示要写入的文件对象。

```python
print("What is your student #?")   # 默认换行输出

x = 'I love '
y = 'Baymax.'
print(x, y)              # I love Baymax.

print(x, end = '')       # 不换行
print(y)                 # I love Baymax.

print("isbd", "ruc", "edu", "cn", sep=".")   # isbd.ruc.edu.cn
```

### 格式化输出

`%s` 表示输出为字符串，`%d` 表示整数，`%f` 表示浮点数：

```python
print("My name is %s and weight is %5.2f kg!" % ('Garfield', 50))
# My name is Garfield and weight is 50.00 kg!

print("My name is %s and weight is %d kg!" % ('Garfield', 50))
# My name is Garfield and weight is 50 kg!
```

**禁止转义字符 r/R**：让 print 的内容按照字符串字面的意思来使用。

```python
print(r'\n')   # \n
print(R'\n')   # \n
```

## 变量与赋值

通过等号把变量值赋值给变量名：`变量名 = 变量值`。尚未赋值的变量名应该在等号左边，取值在等号右边。

```python
a = 5        # a 的值就是 5
b = 6
a + b        # 11
c = a + 6
d = c + 7    # d = 18
quarter = 1/4
half = 2 * quarter   # 0.5
```

**重要**：仅仅是表达式的当前值赋给了当前的名称。如果这个值以后改变了，则由这个值定义的其他名称将不会改变取值。如果需要改变取值，需要重新赋值。

```python
quarter = 4
half      # 0.5（不随 quarter 改变）
half = 2 * quarter   # 重新赋值后为 8
```

### 命名规则

- 变量名必须要用字母开头，可以包含字母和数字，并且区分大小写；
- 名称不能包含空格，通常使用下划线 `_` 来替换每个空格；
- 变量名不能用数字开头；
- 变量名不能使用保留字；
- Python 可以给出中文变量名（如 `我 = 3`）。

```python
var_1 = 2
purchase_price = 5
state_tax_rate = 0.075
county_tax_rate = 0.02
city_tax_rate = 0
sales_tax_rate = state_tax_rate + county_tax_rate + city_tax_rate
sales_tax = purchase_price * sales_tax_rate
```

使用 `del` 语句可以删除单个或多个对象：`del purchase_price, sales_tax_rate`。

### 多变量赋值

```python
a = b = c = 1      # 三个变量被分配到相同的内存空间上
a, b, c = 1, 2, 3  # 整型对象 1, 2, 3 分别分配给 a, b, c
```

## 位运算符

位运算符把十进制数字先换算成二进制，再基于二进制计算，输出结果按十进制显示。以 a = 60（二进制 00111100）和 b = 13（二进制 00001101）为例：

| 运算符 | 描述 | 实例 |
|---|---|---|
| `&` | 与：两个相应数位都为 1，返回 1，否则为 0 | a&b=12（00001100） |
| `\|` | 或：相应数位有一个为 1，返回 1，否则为 0 | a\|b=61（00111101） |
| `^` | 异或：两个相应数位不同时，返回 1 | a^b=49（00110001） |
| `~` | 数位取反：把 1 变为 0，把 0 变为 1 | ~a=-61（11000011） |
| `<<` | 左移若干位：高位保留，低位补 0（其他大部分语言高位丢弃） | a<<2=240（11110000） |
| `>>` | 右移若干位：低位丢弃，正数高位补 0，负数高位补 1 | a>>2=15 |

注 1（取反）：当二进制数为正数时，其反码、补码和原码相同。表示有符号数时最高位为符号位（0 正 1 负）。负数时保持最高位符号位不变，将数值位按位求反（得到反码），然后在最低位加 1 得到补码。

注 2（移位）：由于 Python 可以处理任意大的整数，左移运算符不会把高位的数字 1 丢弃，而是继续保留，低位用 0 补齐。如果原始数据是负数，转为二进制后最高位是 1，右移时高位用 1 而不是 0 补齐。

```python
a = 60
b = 13
a & b      # 12
a | b      # 61
a ^ b      # 49
~a         # -61
a << 2     # 240
a >> 2     # 15
```

## 逻辑运算符

| 运算符 | 逻辑表达式 | 描述 | 返回 |
|---|---|---|---|
| `and` | a and b | 如果 a 为 False，返回 False，否则返回 b 的值 | 13 |
| `or` | a or b | 如果 a 为 True，返回 a 的值，否则返回 b 的值 | 60 |
| `not` | not a | 如果 a 为 True，返回 False；反之，返回 True | False |

```python
a1, b1 = 1, 2
a1 and b1    # 2
a1 or b1     # 1
a2, b2 = 0, 2
a2 and b2    # 0
a2 or b2     # 2
```

## 成员运算符

判断一个字符（串）是否在另外一个字符串中。

| 运算符 | 描述 |
|---|---|
| `in` | a in b：如果 a 在 b 中，返回 True，否则为 False |
| `not in` | a not in b：如果 a 不在 b 中，返回 True，否则为 False |

```python
'Tom' in 'Tom and Jerry'      # True
'Jerry' not in 'Tom and Jerry'  # False

```

## 身份运算符

用于比较两个对象的存储单元。`id()` 函数用于获取对象的内存地址。

| 运算符 | 描述 |
|---|---|
| `is` | a is b：类似 id(a)==id(b)，引用同一对象，返回 True，否则 False |
| `is not` | a is not b：类似 id(a)!=id(b)，引用不同对象，返回 True，否则 False |

**is 与 == 区别**：`is` 用于判断两个变量引用对象是否为同一个，`==` 用于判断引用变量的值是否相等。

```python
a = b = 8
a is b        # True
a, b = 8, 18
a is b        # False

a = [1, 2, 3]
b = a
b is a        # True
b == a        # True
id(a), id(b)  # 相同

b = a[:]      # 切片复制
b is a        # False
b == a        # True
id(a), id(b)  # 不同
```

## 比较运算符

比较运算符的运行结果一般为布尔值。

| 比较 | 操作符 | 结果为 True 例子 | 结果为 False 例子 |
|---|---|---|---|
| 小于 | `<` | 2 < 3 | 2 < 2 |
| 大于 | `>` | 3 > 2 | 3 > 3 |
| 小于等于 | `<=` | 2 <= 2 | 3 <= 2 |
| 大于等于 | `>=` | 3 >= 3 | 2 >= 3 |
| 等于 | `==` | 3 == 3 | 3 == 2 |
| 不等于 | `!=` | 3 != 2 | 2 != 2 |

一个表达式可以包含多个比较，并且为了使整个表达式为真，它们都必须为真。

```python
3 > 1 + 1               # True
1 < 1 + 1 < 3           # True
x, y = 12, 5
min(x, y) <= (x+y)/2 <= max(x, y)   # True
"Dog" > "Catastrophe" > "Cat"       # True（字符串按字典顺序比较）
```


### range 函数

`range(start, stop[, step])` 可创建一个整数列表，一般用在 for 循环中。start 计数从 start 开始（默认 0）；stop 计数到 stop 结束但不包括 stop；step 步长默认 1。

```python
for i in range(2):
    print(i)      # 0 \n 1
for i in range(1, 5, 2):
    print(i)      # 1 \n 3
for i in range(2):
    print(i, end='')   # 01（不换行）
```

### math 模块

很多函数存储在称为模块（module）的函数集合中，使用前需要导入。数学运算常用函数基本都在 math 模块中。

```python
import math
math.sqrt(1)     # 1.0
math.sqrt(9)     # 3.0
math.sin(1)      # 0.8414709848078965
math.e           # 2.718281828459045
math.pi          # 3.141592653589793
```

常用三角函数：`acos(x)` 反余弦弧度值；`asin(x)` 反正弦弧度值；`atan(x)` 反正切弧度值；`cos(x)` 弧度的余弦值；`hypot(x,y)` 欧几里得范数 sqrt(x*x+y*y)；`sin(x)` 弧度的正弦值；`tan(x)` 弧度的正切值；`degrees(x)` 弧度转角度（degrees(math.pi/2)=90.0）；`radians(x)` 角度转弧度。

导入模块后可用 `dir` 函数查看模块中包含的函数（如 `dir(math)`）。

math 模块中常用的数学函数：

| 函数 | 返回值（描述） |
|---|---|
| `ceil(x)` | 上入整数，如 math.ceil(4.1) 返回 5 |
| `exp(x)` | e 的 x 次幂，如 math.exp(1) 返回 2.718281828459045 |
| `floor(x)` | 下舍整数，如 math.floor(4.9) 返回 4 |
| `log(x)` | 如 math.log(math.e) 返回 1.0，math.log(100,10) 返回 2.0 |
| `pow(x,y)` | x**y 运算后的值 |
| `round(x[,n])` | 四舍五入值，n 代表小数点后的位数 |
| `sqrt(x)` | 返回 x 的平方根 |

### cmath 模块

cmath 模块包含一些用于复数运算的函数：

```python
import cmath
cmath.sqrt(-1)       # 1j
cmath.sqrt(9)        # (3+0j)
cmath.sin(1)         # (0.8414709848078965+0j)
cmath.log10(100)     # (2+0j)
```

### help 函数

如果忘记了模块中函数的使用方法，可以用 `help` 函数查看帮助文件。方括号中的参数表示可选参数，不给出则使用默认值。

```python
help(math.log)
math.log(16, 2) / math.log(2)   # 4.0
math.log(16) / math.log(2)      # 4.0（换底公式）
```

Jupyter 中：输入名称开头字母后按 Tab 键可补全；在名称后面放置一个问号 `math.log?` 可查看函数信息。

### operator 模块

operator 模块提供一些常用的逻辑比较以及算术运算的操作。

```python
import math
import operator
math.sqrt(operator.add(4, 5))   # 3.0
operator.lt(1, 3)               # True（等价于 1 <= 3，即 1 < 3）
```

对应关系：`operator.lt(a,b)` 等价于 `a<b`；`le` 等价于 `a<=b`；`eq` 等价于 `a==b`；`ne` 等价于 `a!=b`；`ge` 等价于 `a>=b`；`gt` 等价于 `a>b`。

### random 模块

常用的随机数函数包含在 random 模块中：

```python
import random
random.choice(range(10))          # 从序列中随机挑选一个元素
random.randint(0, 1)              # 含 start 和 stop 范围内随机生成一个整数
random.randrange(10, 100, 2)      # 从 [10, 12, ..., 96, 98] 序列中获取一个随机数
```

常用随机数函数表：

| 函数 | 描述 |
|---|---|
| `choice(seq)` | 从指定序列中随机挑选一个元素 |
| `randrange([start,]stop[,step])` | 从指定范围内获取一个随机数 |
| `randint(start, stop)` | 从含 start 和 stop 范围内随机生成一个整数 |
| `random()` | 在 [0,1) 范围内随机生成一个实数 |
| `seed([x])` | 改变随机数生成器的种子 seed |
| `shuffle(lst)` | 将序列的所有元素随机排序 |
| `uniform(x,y)` | 在 [x,y] 范围内随机生成下一个实数 |
| `sample(lst, k)` | 从序列 lst 中随机获取指定长度 k 的序列 |
