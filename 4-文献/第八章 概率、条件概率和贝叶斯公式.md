## 引言

对数据集进行简单可视化处理（散点图、直方图）或简单代数计算（求平均值）能大致了解数据信息。但大多数情况下我们希望更进一步，从数据中挖掘更一般性、更深刻的结论：探索数据是如何生成的、根据以往数据对未来结果做出预测、或从对数据总体的多个猜测中找出最合理的一个。这些正是**统计推断**所关注的内容。

统计推断的基础是**随机性（randomness）**。随机性用来描述某事件集合中的各个事件是否发生的不确定性，但这种结果还是有规律可循的（如抛硬币的结果随机，但一定是正/反之一，均匀硬币两面频率大体接近）。**偶然性**更多描述完全预料之外的结果（如硬币抛到空中后没有掉下来、找不到了）。

对随机性的度量用**概率（probability）**，反映某事件发生可能性的大小。在概率的基础上延伸到**条件概率（conditional probability）**：若事件 A 已经发生，事件 B 发生的概率。本章引入概率、条件概率以及密切相关的概率分布、随机变量等的定义，详细介绍计算条件概率的**贝叶斯公式（Bayes rule）**，并通过若干案例展现其实际应用。

## 概率

概率是对一个事件发生可能性的度量，记作 P 或者 Pr。

- **主观概率**：如"今年在北京地区参加高考能考上中国人民大学"的概率可认为 0.5。概率的取值总在 0 和 1 之间，取值越大表明发生的可能性越大；
- **0 概率事件**：发生概率为 0 的事件，但不等于不可能发生的事件；同理概率为 1 的事件不一定是必然事件（本章忽略这些细微区别）；
- **客观计算**：掷骰子（中心对称的正方体），出现每个面 $\{1,2,3,4,5,6\}$ 朝上的概率均为 1/6，即 $\Pr(\text{出现点数 } k)=1/6$，$k=1,2,\ldots,6$。

### 辛普森案件（0.9999 与 1）

- 数学上无限循环小数 $0.9999\cdots=1$；但有限位 0.9999 与 1 很不一样；
- 1994 年 O.J. Simpson（前美式橄榄球明星）杀妻案：检方 DNA 血手套相似概率 0.9999；辩方提出血手套戴不进、抽血量与存血量不符（7ml 抽血剩 5.5ml）、无目击者、未找到凶器、时间仓促（作案到飞机起飞仅半小时）等疑点；因警方重大失误导致关键证据失效，1995 年 10 月 3 日 12 位陪审团一致判无罪（疑罪从无）；1997 年民事判定辛普森赔偿 3350 万美元；
- **启示**：0.9999 的概率在法庭上只是可能性，只要不是 100%，就不能仅依此一项证据定罪。

## 概率的性质

- 全事件（所有可能出现结果的全体）常用 $\Omega$ 表示，$\Pr(\Omega)=1$；
- 空事件 $\Pr(\emptyset)=0$；
- **可加性**：对 N 个互不相交的事件 $A_1,A_2,\ldots,A_N$，有

$$\Pr(A_{1}\cup A_{2}\cup\cdots\cup A_{N})=\sum_{i=1}^{N}\Pr(A_{i}).$$

对无穷可数的互不相交事件仍然成立。特别地，对两个不相交事件 A 和 B，$\Pr(A\cup B)=\Pr(A)+\Pr(B)$。

掷骰子例子：

- $\Pr(\text{出现点数 }100)=0$；
- $\Pr(\text{出现点数小于 7 大于 0})=1$；
- $\Pr(\text{出现点数为 2 或者 3})=\Pr(\text{出现点数 2})+\Pr(\text{出现点数 3})=1/3$。

## 条件概率

条件概率指的是：对于两个事件 A 和 B，若事件 B 已经发生，事件 A 发生的概率大小，记作 $\Pr(A\mid B)$。定义依赖于概率：

$$\Pr(A\mid B)=\frac{\Pr(A\cap B)}{\Pr(B)} \tag{1}$$

- $A\mid B$：在事件 B 发生的情况下的事件 A；
- $A\cap B$（也可写成 AB）：事件 A 和 B 的交，即同时发生；$\Pr(A\cap B)$ 也称为**联合概率**；
- 公式含义：在事件 B 发生的情况下发生事件 A 的概率，等于事件 A 和 B 同时发生的概率除以事件 B 发生的概率。

**掷骰子例子**：事件 A = "出现点数为 $\{3,4,5\}$ 中的一个"，事件 B = "出现点数为 $\{2,3,4\}$ 中的一个"。

- $\Pr(A\cap B)=\Pr(\{\text{出现点数为 3 或者 4}\})=1/3$；
- $\Pr(B)=\Pr(\{\text{出现点数为 2,3,4 的一个}\})=1/2$；

因此 $\Pr(A\mid B)=2/3$，即在已知点数为 $\{2,3,4\}$ 中一个的情况下，点数其实是 $\{3,4,5\}$ 中一个的概率为 2/3。

**韦恩图理解**：$\Pr(A\mid B)$ 为在圆 B 的范围内发生事件 A 的可能性，即 AB 的面积除以 B 的面积。

```python
# 韦恩图（需安装 matplotlib-venn）
from matplotlib_venn import venn2
v = venn2(subsets=(2, 3, 1), set_labels=(' ', ' '))
# subsets 中三个元素分别代表 A\B, B\A, AB 的面积
v.get_label_by_id('10').set_text('A')
v.get_label_by_id('11').set_text('AB')
v.get_label_by_id('01').set_text('B')
```

### 重要说明

- **不对空事件取条件**，条件概率公式中分母的取值范围是 $(0,1]$，不可能取到 0；因此条件概率 $\Pr(A\mid B)$ 大于或等于联合概率 $\Pr(AB)$；
- **为什么要除以 $\Pr(B)$**：在已知事件 B 发生的条件下，考虑的可能性空间缩小到了事件 B 发生的范围内，然后将该范围内 A 发生的可能性除以 B 发生的可能性；
- **所有的概率本质上都是条件概率**：概率可以看成给定全事件后的条件概率。谈概率时总是存在这样或那样的模型、假设或条件（如抛硬币正面概率为 1/2 取决于对硬币无偏性的假设）。

## 辛普森悖论

英国统计学家 E.H. Simpson（1951 年论文）指出：在某些情况下，**在分组比较中占优势的一方，可能在合并后的总评中成为失势的一方**。注意这个辛普森是英国统计学家，不是辛普森案件中的美国橄榄球明星 O.J. Simpson。

### 案例一：医院治愈率

假设一个人生病，从两家医院选择。医院 A 治愈率 90%，医院 B 治愈率 80%。

| 医院 A | 治愈数 | 总数 | 治愈率 |
|---|---|---|---|
| 严重 | 30 | 100 | 30% |
| 不严重 | 870 | 900 | 96.7% |
| 合计 | 900 | 1000 | 90% |

| 医院 B | 治愈数 | 总数 | 治愈率 |
|---|---|---|---|
| 严重 | 210 | 400 | 52.5% |
| 不严重 | 590 | 600 | 98.3% |
| 合计 | 800 | 1000 | 80% |

$$\Pr(\text{医院A能治愈}\mid\text{严重})=0.3<0.525=\Pr(\text{医院B能治愈}\mid\text{严重})$$

$$\Pr(\text{医院A能治愈}\mid\text{不严重})=0.967<0.983=\Pr(\text{医院B能治愈}\mid\text{不严重})$$

尽管总体治愈率 A 高，但给定病情严重程度后，B 的治愈率总高于 A。**原因**：两家医院中"严重"与"不严重"病人组的比例相差较大。当两家医院具有相同的"严重/不严重"人数比例时，如果 B 在每组治愈率都大于 A，则 B 的总体治愈率肯定大于 A。

### 案例四：房价悖论

某市 2010 年比 2011 年每平米均价下降 250 元、下降 2%（2010 均价 12500 元/平米、2011 均价 12250 元/平米）；但 2010 年成交主要在市（市区），2011 年主要在市郊。分市区/郊区看，2011 年市区均价 1.6 万元/平米（2010 为 1.5 万）、郊区 1.1 万（2010 为 1.0 万），两年各类别均价均上升，但总体均价反而下降。

## 贝叶斯公式

### 曲奇饼问题

有两碗曲奇饼：碗 1 含 30 个香草 + 10 个巧克力；碗 2 含两种各 20 个。

```python
df = pd.DataFrame({'碗1': {'香草曲奇饼': 30, '巧克力曲奇饼': 10},
                   '碗2': {'香草曲奇饼': 20, '巧克力曲奇饼': 20}})
```

不看的情况下随机挑一个碗并随机拿一块曲奇饼，得到香草曲奇饼。问：这块香草曲奇饼来自碗 1 的概率？

$\Pr(\text{香草}\mid\text{碗1})=30/40=3/4$ 容易计算，但我们要的是 $\Pr(\text{碗1}\mid\text{香草})$。两者不相等，但贝叶斯公式可以通过容易计算的量得到目标。

考虑两个互不相交的事件 $A_1$（抽到碗 1）、$A_2$（抽到碗 2），其并构成全事件 $\Omega$；事件 B 表示观察到的事件（取到香草曲奇饼）。贝叶斯公式：

$$\Pr(A_{1}\mid B)=\frac{\Pr(A_{1})\Pr(B\mid A_{1})}{\Pr(A_{1})\Pr(B\mid A_{1})+\Pr(A_{2})\Pr(B\mid A_{2})}.$$

- $\Pr(A_1)=1/2$（随机公平选碗）；
- $\Pr(B\mid A_1)=3/4$（从碗 1 拿香草的概率）；
- $\Pr(B\mid A_2)=1/2$（从碗 2 拿香草的概率）。

$$\Pr(A_{1}\mid B)=\frac{3}{5}.$$

即香草曲奇饼来自碗 1 的概率为 0.6，来自碗 1 比来自碗 2 的可能性更大一点。

### 一般形式

一般地，对 K 个互不相交的事件 $A_1,\ldots,A_K$ 且它们组成全事件 $\Omega$，对某一事件 B：

$$\Pr(A_{1}\mid B)=\Pr(A_{1})\Pr(B\mid A_{1})\Bigg/\sum_{k=1}^{K}\Pr(A_{k})\Pr(B\mid A_{k}).$$

该公式由英格兰数学家托马斯·贝叶斯（Thomas Bayes, 1702-1761）提出，因此叫**贝叶斯公式**。

- $\Pr(A_k)$：**先验概率（prior probability）**；
- $\Pr(A_k\mid B)$：**后验概率（posterior probability）**。

### 疾病检测案例

人群中染上某种疾病的概率是 0.1%；诊断将实际患病人正确诊断为患病的概率是 80%，将正常人错误诊断为患病的概率是 0.05%。问：呈阳性结果是否可靠？

设 $A_1$ 为真实患者（$\Pr(A_1)=0.1\%$），$A_2$ 为正常人（$\Pr(A_2)=1-0.001$）；B 为诊断呈阳性。$\Pr(B\mid A_1)=80\%$，$\Pr(B\mid A_2)=0.05\%$。

计算诊断呈阳性但实际并没有患病（即 $A_2$）的概率：

$$\Pr(A_{2}\mid B)=\frac{\Pr(B\mid A_{2})\Pr(A_{2})}{\Pr(B\mid A_{1})\Pr(A_{1})+\Pr(B\mid A_{2})\Pr(A_{2})}$$

```python
0.0005 * (1 - 0.001) / (0.0005 * (1 - 0.001) + 0.8 * 0.001)
# 0.3843786071565987
```

虽然诊断结果是阳性，但是其为正常人的概率却很高，约 38%。因此在校医院体检呈阳性不必慌张，较大可能是错误诊断，你仍然是正常的。

### M&M 豆问题

Mars 公司变更不同颜色巧克力豆的混合比例：

- 1995 年推出蓝色豆。此前普通一袋：30% 褐色、20% 黄色、20% 红色、10% 绿色、10% 橙色、10% 黄褐色；
- 之后变为：24% 蓝色、20% 绿色、16% 橙色、14% 黄色、13% 红色、13% 褐色（取消黄褐色）。

朋友有两袋 M&M 豆，一袋 1994 年、一袋 1996 年，但没告诉具体哪袋是哪年。他从每袋各取一个豆给我：一个是黄色、一个是绿色，记作事件 B。问黄色豆来自 1994 年的袋子的概率？

- 假设 1（$A_1$）：袋 1 是 1994 年的，袋 2 是 1996 年的；
- 假设 2（$A_2$）：袋 1 是 1996 年的，袋 2 是 1994 年的。

|  | 先验概率 Pr(A) | Pr(B \| A) | Pr(A)Pr(B \| A) | 后验概率 Pr(A \| B) |
|---|---|---|---|---|
| 假设 1 | 1/2 | 0.2 × 0.2 | 0.02 | 20/27 |
| 假设 2 | 1/2 | 0.14 × 0.1 | 0.007 | 7/27 |

如果假设 1 为真：黄色豆来自 1994 年袋的概率 20%，绿色来自 1996 年袋的概率 20%；选择独立，故相乘得 $\Pr(B\mid A_1)$。第三列由前两列相乘，最后一列归一化得到后验。结论：袋 1 是 1994 年、袋 2 是 1996 年的概率更高（20/27 ≈ 0.74）。

### Monty Hall 问题（三门问题）

游戏节目"来做个交易"。三扇门，两扇门后是羚羊，一扇门后是奔驰车。选中一扇门后，主持人会打开剩下两扇门中是羚羊的一扇。问是否更换选择？

直觉认为没有区别，但**坚持最初选择中奖概率只有 1/3，更换后中奖概率为 2/3**。

**贝叶斯公式解释**：设三个门为 a、b、c，你选择门 a；事件 B 表示主持人打开了门 b 且门 b 后没有车。假设：$A_1$ 车在 a 后；$A_2$ 车在 b 后；$A_3$ 车在 c 后。

|  | $\Pr(A_k)$ | $\Pr(B\mid A_k)$ | $\Pr(A_k)\Pr(B\mid A_k)$ | $\Pr(A_k\mid B)$ |
|---|---|---|---|---|
| 车在门 a 后 | 1/3 | 1/2 | 1/6 | 1/3 |
| 车在门 b 后 | 1/3 | 0 | 0 | 0 |
| 车在门 c 后 | 1/3 | 1 | 1/3 | 2/3 |

- 假设 1（车在 a）：主持人可随意打开 b 或 c，打开 b 的概率 1/2；
- 假设 2（车在 b）：主持人不得不打开 c，打开 b 的概率 0；
- 假设 3（车在 c）：主持人打开 b 的概率是 1。

结论：最好换掉最初的选择。

**变形**：若主持人总是尽可能选择门 b，只有迫不得已才选择门 c：

|  | $\Pr(A_k)$ | $\Pr(B\mid A_k)$ | $\Pr(A_k)\Pr(B\mid A_k)$ | $\Pr(A_k\mid B)$ |
|---|---|---|---|---|
| 车在门 a 后 | 1/3 | 1 | 1/3 | 1/2 |
| 车在门 b 后 | 1/3 | 0 | 0 | 0 |
| 车在门 c 后 | 1/3 | 1 | 1/3 | 1/2 |

此时改变最初选择与否对结果影响无关紧要。贝叶斯方法的优势之一就是可以推广到各种变形问题的处理。

## 随机变量和概率分布

**随机变量（random variable）** 用来描述某个未发生事件的结果。例如从中国人民大学选一位学生测量血压，用随机变量 X 表示；由于测量误差，X 总是在未知真实血压附近波动，具有随机性。血压的随机性到底如何，用**概率分布（probability distribution）**来刻画。

**伯努利分布（Bernoulli distribution）**：掷硬币，$X=1$ 表示正面朝上，$X=0$ 表示背面朝上，则 $\Pr(X=1)$ 表达正面朝上的概率。

**正态分布（normal distribution）**：形态为钟型曲线。由于随机误差的影响，测量值大概率在真实值附近，也不会偏得太厉害。其概率密度函数（probability density function, pdf）：

$$\mathrm{pdf}(x\mid\mu,\sigma)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^{2}}{2\sigma^{2}}} \tag{3}$$

- $\mu$：均值，取值范围任意实数；
- $\sigma$：标准差，衡量分布离散程度，取值只能为正。

用 Python 画不同参数下的正态 pdf（scipy.stats 包含很多统计函数；seaborn 是基于 matplotlib 的可视化包）：

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats
import seaborn as sns

mu_params = [-1, 0, 1]
sd_params = [0.5, 1, 1.5]
x = np.linspace(-7, 7, 100)
f, ax = plt.subplots(len(mu_params), len(sd_params), sharex=True, sharey=True)

for i in range(3):
    for j in range(3):
        mu = mu_params[i]
        sd = sd_params[j]
        y = stats.norm(mu, sd).pdf(x)
        ax[i, j].plot(x, y)
        ax[i, j].plot(0, 0, label="$\mu$={:3.2f}\n$\sigma$={:3.2f}".format(mu, sd), alpha=0)
        ax[i, j].legend(fontsize=5)

ax[2, 1].set_xlabel('$x$', fontsize=16)
ax[1, 0].set_ylabel('$pdf(x)$', fontsize=16)
plt.savefig('fig_normal_pdf.jpg', dpi=500)
plt.show()
```

**规律**：$\mu$ 刻画均值，$\mu$ 越大钟型曲线越往右移；$\sigma$ 刻画波动范围，$\sigma$ 越大曲线越矮胖，$\sigma$ 越小曲线越瘦高。

通常记为：$X\sim N(\mu,\sigma^{2}) \tag{4}$，符号 $\sim$ 读作"服从于某种分布"。

**随机变量的分类**：

- **连续随机变量**：可从某个区间内取任意值，取值不可数，如正态随机变量；
- **离散随机变量**：只能取某些特定的离散值，取值有限或可数，如伯努利随机变量。

**独立性**：如果两个随机变量 X 和 Y 对所有可能的取值都满足 $\mathrm{pdf}(x,y)=\mathrm{pdf}(x)\mathrm{pdf}(y)$，则称两个随机变量相互独立。**独立同分布（iid）**：对服从同一个分布的多个随机变量进行连续采样，各个变量的采样值之间相互独立。

## scipy.stats 与随机数产生

scipy 服务于数学、科学、工程等领域的科学计算；本章主要使用 scipy 的 stats 子模块。scipy.stats 中离散分布 13 个、连续分布 94 个、多元分布 8 个。对每个分布可以得到：

- pdf（连续变量的概率密度函数）或 pmf（离散变量的概率质量函数，probability mass function）；
- cdf（累积分布函数）；ppf（分位数，percent point function，即 cdf 的反函数）；
- rvs（随机数）；logpdf；logcdf；sf（生存函数）；mean；variance；skewness（偏度）；kurtosis（峰度）；非中心矩等。

### 标准正态分布的绘图

```python
plt.figure(figsize=(10, 9))
x = np.arange(-4, 4, 0.01)

# cdf
plt.subplot(2, 2, 1)
plt.plot(x, stats.norm.cdf(x))
plt.title('cdf of $N(0,1): \Phi(x)$')

# pdf
plt.subplot(2, 2, 2)
plt.plot(x, stats.norm.pdf(x))
plt.title('pdf of $N(0,1): \phi(x)$')

# 生存函数 sf
plt.subplot(2, 2, 3)
plt.plot(x, stats.norm.sf(x))
plt.title('sf of $N(0,1): 1-\Phi(x)$')

# 逆累积分布函数 ppf
plt.subplot(2, 2, 4)
plt.plot(x, stats.norm.ppf(x))
plt.title('ppf of $N(0,1): \Phi^{-1}(x)$')
plt.savefig('figs_normal.jpg', dpi=500)
plt.show()
```

### 产生正态随机数

```python
# 固定随机种子 1010 以重现结果
np.random.seed(1010)
stats.norm.rvs(size=10, loc=5, scale=2)
# array([2.6491042, 4.23370464, 2.05726764, 1.39886295, 5.26020084,
#        8.19123725, 6.98632135, 0.27258561, 4.04081547, 1.69923611])

# 也可以在函数中设定随机种子
stats.norm.rvs(size=10, random_state=1010, loc=5, scale=2)
```

**注意区别**：`stats.norm.rvs(10)` 产生一个服从均值 10、标准差 1 的随机数；`stats.norm.rvs(size=10)` 产生 10 个标准正态随机数。

反复使用某个分布可赋值给对象：

```python
fr = stats.norm(loc=5, scale=2)
print(fr.rvs(size=5, random_state=1010))
print(fr.mean(), fr.std(), fr.cdf(5.97), fr.pdf([-0.5, 2.96]),
      fr.stats(moments='mvsk'), fr.kwds)
# 5.0 2.0 0.6861618272430887 [0.00454678 0.11856598]
# (array(5.), array(4.), array(0.), array(0.)) {'loc': 5, 'scale': 2}
```

`mvsk` 分别指均值（mean）、方差（variance）、偏度（skewness）、峰度（kurtosis），默认值是 "mv"。

右侧尾临界值表（isf = inverse survival function，与 ppf 结果一致）：

```python
stats.norm.isf([0.1, 0.05, 0.025, 0.01, 0.001])
# array([1.28155157, 1.64485363, 1.95996398, 2.32634787, 3.09023231])
```

从正态分布抽 10000 个样本画 pdf 与直方图对比：

```python
from scipy.stats import norm
```

## numpy 模块中随机数的产生

### np.random.random / rand

```python
np.random.random(5)          # 生成 (0,1) 中的 5 个随机浮点数
np.random.random([2, 3])     # 2×3 随机样本阵列（也可写 np.random.random((2,3))）
# 一般地，np.random.random((d0, d1, ..., dn)) 返回 d0×...×dn 的随机样本阵列，来自 [0,1) 均匀分布
np.random.rand(2, 2)         # 与 np.random.random 功能相同
```

### np.random.randn / standard_normal

```python
np.random.randn(2, 3)        # 来自标准正态分布的 d0×...×dn 随机样本阵列
# 输入通常为整数，若为浮点数会自动直接截断转换为整数
np.random.standard_normal((2, 5))   # 与 randn 类似，但输入参数为元组 (tuple)
```

### np.random.randint

`np.random.randint(low, high=None, size=None, dtype='l')`：生成整数或 n 维整数数组。若 high 不为 None，取 [low, high) 之间的随机整数；否则取 [0, low) 之间。dtype 选择输出格式（int32、int64、uint8 等）。

```python
np.random.randint(3, 10, size=(2, 5))
d = np.random.randint(3, 10, size=(2, 5), dtype='int64')
d.dtype   # dtype('int64')
```

### np.random.choice

`numpy.random.choice(a, size=None, replace=True, p=None)`：从序列中获取元素。

- 若 a 为整数，元素取值为 np.arange(a) 中的随机数；若 a 为数组，元素取值为 a 数组元素中的随机元素；
- `replace`：是否有放回抽样。True 可以抽出重复元素，False 抽出的元素不放回；
- `p`：每个元素被抽取的概率。

```python
np.random.choice(a=5, size=3, replace=False, p=[0.2, 0.1, 0.3, 0.4, 0.0])
# array([3, 0, 2])
np.random.choice(a=['d', 'e', 'f', 'g', 'h'], size=3, replace=False,
                 p=[0.2, 0.1, 0.3, 0.4, 0.0])
# array(['e', 'd', 'g'], dtype='U1')
```

### shuffle / permutation

```python
items = [1, 2, 3, 4, 5, 6]
np.random.shuffle(items)     # 对 x 进行重排序；多维数组只沿第一条轴洗牌，输出为 None
items                        # 例如 [4, 6, 1, 5, 3, 2]

item1 = np.array([1, 2, 3, 4, 5, 6])
item2 = np.random.permutation(item1)   # 与 shuffle 功能类似，但 permutation 不会修改原序列顺序
print(item1)   # [1 2 3 4 5 6]
print(item2)   # 例如 [5 6 1 3 4 2]
```
