## matplotlib 简介

数据可视化通过图形直观地展示数据，好处在于直观、醒目、简单。本章主要学习可视化模块 **matplotlib**，其中应用最广的是 **matplotlib.pyplot**——绘制平面（二维）图形的常用模块。

- 画图风格非常接近 MATLAB，命令使用方式与 MATLAB 中的画图命令差不多；
- 命名由来：MATLAB 的前三个字母（mat）+ plot（绘图功能）+ lib（库，集成许多功能）。

本章以 matplotlib.pyplot 为基础，讲述 6 种基础统计图形：**散点图、折线图、柱状图、饼图、箱线图和概率图**，另外简单提一下直方图。

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
```

## 绘图三步

**第一步：构建画图区域**

| 函数名称 | 函数作用 |
|---|---|
| `plt.figure` | 在指定区域画一幅图形，可指定区域大小、像素 |
| `plt.subplot` | 在指定区域画多幅子图，可指定子图行列数和编号 |
| `plt.add_subplot` | 在指定区域画多幅子图，可指定子图行列数和编号 |

**第二步：绘制图形、添加标签**（绘制图形是主要工作；可以先绘制图形，也可以先添加各类标签，但**添加图例一定要在绘制图形之后**）

| 函数名称 | 函数作用 |
|---|---|
| `plt.title` | 在当前图形中添加标题 |
| `plt.xlabel` | 在当前图形中添加横轴名称 |
| `plt.ylabel` | 在当前图形中添加纵轴名称 |
| `plt.xlim` | 当前图形横轴的范围 |
| `plt.ylim` | 当前图形纵轴的范围 |
| `plt.xticks` | 横轴刻度的数目与数值 |
| `plt.yticks` | 纵轴刻度的数目与数值 |
| `plt.legend` | 当前图形的图例，可指定大小、位置、标签 |

**第三步：保存和显示图形**

| 函数名称 | 函数作用 |
|---|---|
| `plt.savefig` | 保存绘制的图形 |
| `plt.show` | 在本机显示图形 |

最简单的绘图可以省略第一部分，直接在默认区域绘制。多数参数都有默认取值。

## 散点图 scatter

散点图利用坐标点的分布形态反映特征间的统计关系。

| 参数名称 | 说明 |
|---|---|
| `x, y` | 数组。横轴和纵轴对应的数据 |
| `s` | 数值或一维数组。指定大小 |
| `c` | 数值或一维数组。指定颜色 |
| `marker` | 特定字符串。指定点的类型 |
| `alpha` | 0~1 的小数。点的透明度 |

调用 scatter 时第一个参数给出横轴取值，第二个参数给出纵轴取值，**两个参数的长度必须一样**，否则报错。

> 提示：暂时不要尝试用中文表示坐标轴标签或标题——程序不会报错，但中文有时不能正确显示。后面有相关案例教如何显示中文。

```python
# 简单散点图（5 个点 (1,2),(2,6),(3,10),(4,14),(5,18)）
# plt.scatter(x, y)，再 plt.xlabel/plt.ylabel/plt.title/plt.show

# 用关键词从字典提取数据画气泡图
data = {'a': np.arange(50), 'c': np.random.randint(0, 50, 50), 'd': np.random.randn(50)}
data['b'] = data['a'] + 10 * np.random.randn(50)
data['d'] = np.abs(data['d']) * 100
plt.scatter('a', 'b', c='c', s='d', data=data)
plt.xlabel('a')
plt.ylabel('b')
plt.show()
```

## 折线图 plot

折线图将数据点成对展示并连接起来，可以看作按横轴坐标顺序连接散点。主要查看纵轴变量随横轴变量改变的趋势。调用 plot 时，第一个参数给出横轴取值，第二个参数给出纵轴取值，**两个参数的长度必须一样**。

| 参数名称 | 说明 |
|---|---|
| `x, y` | 数组。横轴和纵轴对应的数据 |
| `color` | 特定字符串。指定线条颜色 |
| `linestyle` | 特定字符串。指定线条类型 |
| `marker` | 特定字符串。表示点的类型 |
| `alpha` | 0~1 之间的小数。点的透明度 |

**颜色**：`'b'` 蓝，`'g'` 绿，`'r'` 红，`'c'` 青，`'m'` 品红，`'y'` 黄，`'k'` 黑，`'w'` 白。

```python
plt.plot([1, 2, 3, 4, 5], np.arange(2, 20, 4))   # 折线
plt.xticks([1, 2, 3, 4, 5])
plt.yticks(np.arange(2, 20, 4))
plt.xlabel('Horizontal Axis')
plt.ylabel('Vertical Axis')
plt.title('A Toy Example')
plt.show()
```

**只给一个参数时**：默认该参数是纵轴取值，横轴自动产生从 0 开始的列表与之对应。一旦指定横轴，横轴列表长度必须与纵轴完全一样。

```python
# sin/cos 曲线
X = np.linspace(-np.pi, np.pi, 256, endpoint=True)
C, S = np.cos(X), np.sin(X)
plt.plot(X, C)   # cos 曲线
plt.plot(X, S)   # sin 曲线
plt.show()
```

## 子图

### 方式一：figure + add_subplot

```python
rad = np.arange(0, np.pi*2, 0.01)
p1 = plt.figure(figsize=(8, 6), dpi=80)   # 设置绘图大小与分辨率

# 第一张子图
ax1 = p1.add_subplot(2, 1, 1)
plt.title('lines'); plt.xlabel('x'); plt.ylabel('y')
plt.xlim(0, 1); plt.ylim(0, 1)
plt.xticks([0, 0.2, 0.4, 0.6, 0.8, 1])
plt.yticks([0, 0.2, 0.4, 0.6, 0.8, 1])
plt.plot(rad, rad**2)
plt.plot(rad, rad**4)
plt.legend(['y=x^2', 'y=x^4'])

# 第二张子图
ax2 = p1.add_subplot(2, 1, 2)
plt.title('sin/cos'); plt.xlabel('rad'); plt.ylabel('value')
plt.xlim(0, np.pi*2); plt.ylim(-1, 1)
plt.xticks([0, np.pi/2, np.pi, np.pi*1.5, np.pi*2])
plt.yticks([-1, -0.5, 0, 0.5, 1])
plt.plot(rad, np.sin(rad))
plt.plot(rad, np.cos(rad))
plt.legend(['sin', 'cos'])
plt.show()
```

### 方式二：figure + subplot

```python
def f(t):
    return np.exp(-t) * np.cos(2*np.pi*t)

t1 = np.arange(0, 5, 0.10)
t2 = np.arange(0, 5, 0.02)

plt.figure(1)
plt.subplot(211)                          # 等价于 subplot(2,1,1)
plt.plot(t1, f(t1), 'bo', t2, f(t2), 'k') # 蓝点 + 黑线
plt.subplot(212)
plt.plot(t2, np.cos(2*np.pi*t2), 'r--')   # 红色虚线
plt.show()
```

- `figure(1)` 指令通常没必要（默认产生 figure(1)），可以用 `figure()` 产生更多图形；
- `subplot(211)` 等价于 `subplot(2,1,1)`（只要行数×列数小于 10）；
- `plt.axis([xmin, xmax, ymin, ymax])` 与 `plt.axes([left, bottom, width, height])` 要小心区分：前者设置坐标轴数值范围；后者创建自定义位置/大小的坐标系，所有取值在 0~1 之间；
- `plt.clf()` 清除当前图形；`plt.cla()` 清除当前坐标系；`plt.close()` 完全关闭图形（否则图形所占内存不会完全释放）。

## 线条与点样式配置

matplotlib 的默认配置大多数可以更改，包括图形大小和分辨率（dpi）、线条宽度/颜色/风格、坐标轴、网格、文字与字体属性等。

| 参数名称 | 解释 | 取值 |
|---|---|---|
| `lines.linewidth` | 线条宽度 | 0~10，默认 1.5 |
| `lines.linestyle` | 线条样式 | `-`（实线）、`--`（长虚线）、`-.`（点线）、`:`（短虚线），默认 `-` |
| `lines.marker` | 线条上点的形状 | `o`、`D`、`H` 等 20 多种，默认 None |
| `lines.markersize` | 点的大小 | 0~10，默认 1 |

点形状：`o` 圆圈、`.` 点、`D` 菱形、`s` 正方形、`h` 六边形1、`*` 星号、`H` 六边形2、`d` 小菱形、`-` 水平线、`v` 角朝下三角形、`8` 八边形、`<` 角朝左三角形、`p` 五边形、`>` 角朝右三角形、`,` 像素、`^` 角朝上三角形、`+` 加号、`|` 竖线、`None` 无、`x` X。

```python
plt.plot(np.arange(2, 12, 2), np.arange(2, 20, 4))              # 默认蓝色实线 'b-'
plt.axis([0, 14, 0, 22])
plt.show()

plt.plot(np.arange(2, 12, 2), np.arange(2, 20, 4), 'rs')        # 红色方块
plt.plot(np.arange(2, 12, 2), np.arange(2, 20, 4), 'gv', markersize=20)  # 绿色倒三角，点大小 20
plt.plot(np.arange(2, 12, 2), np.arange(2, 20, 4), 'g.--', linewidth=2)  # 绿色圆点虚线
```

**一幅图多条线**：

```python
t = np.arange(0, 2, 0.1)
plt.plot(t, t, 'r--', linewidth=5)      # 红色虚线
plt.plot(t, t**2.0, 'bs')               # 蓝色方块
plt.plot(t, t**0.5, 'g^')               # 绿色三角
plt.show()

# 等价的一行命令写法：
plt.plot(t, t, 'r--', t, t**2.0, 'bs', t, t**0.5, 'g^', linewidth=5, markersize=5)

# 用关键词控制
t = np.arange(0, 5, 0.2)
plt.plot(t, t**2, color='g', linestyle='-.', linewidth=4.0)
plt.plot(t, t**3, color='r', linestyle='--', linewidth=4.0)
```

`plt.setp(lines)` 可以获取/设置线条的性质（输出较长）。

## 案例：开普勒定律

开普勒三大定律（德国天文学家开普勒，基于第谷·布拉赫 20 多年的观测数据）：

1. **椭圆定律**：所有行星绕太阳的轨道都是椭圆形的，太阳位于椭圆的一个焦点上；
2. **面积定律**：行星和太阳的连线在相等的时间间隔内扫过相等的面积；
3. **调和定律**：所有行星绕太阳一周的恒星时间的平方与它们轨道长半轴的立方成比例。

```python
a = ['水星', '金星', '地球', '火星', '木星', '土星', '天王星', '海王星']
b = [0.241, 0.615, 1.00, 1.88, 11.8, 29.5, 84.0, 165]     # 周期（年）
c = [0.39, 0.72, 1.00, 1.52, 5.20, 9.54, 19.18, 30.06]    # 平均距离
table = pd.DataFrame({'行星': a, '周期（年）': b, '平均距离': c},
                     columns=['行星', '周期（年）', '平均距离'])
table['周期平方/距离立方'] = table['周期（年）']**2 / table['平均距离']**3
```

各行星"周期平方/距离立方"都约等于 1（0.979~1.013），即周期的平方和平均距离的立方成正比——开普勒第三定律。

```python
plt.figure(1, figsize=(9, 4))
plt.subplot(121)
plt.plot(table['周期（年）'], table['平均距离'])
plt.subplot(122)
plt.plot(table['周期（年）']**2, table['平均距离']**3)
plt.show()
```

## 复杂例子与细节控制

### figure 参数

一般的图形大小为 4×3 点；可以用 `figsize=(8,6)` 改为 8×6，`figsize=(12,6)` 增加宽度；`dpi=80` 控制分辨率；`facecolor='g'` 控制背景颜色。

```python
plt.figure(figsize=(8, 6), dpi=80, facecolor='g')
plt.subplot(2, 2, 1)
X = np.linspace(-np.pi, np.pi, 256, endpoint=True)
C, S = np.cos(X), np.sin(X)
plt.plot(X, C, color="blue", linewidth=3.0, linestyle="--")
plt.plot(X, S, color="green", linewidth=3.0, linestyle="--")
plt.xlim(-4.0, 4.0)
plt.ylim(-1.2, 1.2)
plt.xticks(np.linspace(-np.pi, np.pi, 5, endpoint=True))
plt.yticks(np.linspace(-1, 1, 3, endpoint=True))
plt.savefig("SinCos.png", dpi=72)
plt.legend(['cos', 'sin'], loc='lower center', frameon=False)
plt.show()
```

### 图例与 LaTeX 标签

- 图例可在 plot 中加 `label` 参数，再用 `plt.legend(loc='upper left')` 显示；loc 常用 `'best'`；如果忘记 loc 的可选参数，随便给一个值会报错并提示可选取值；
- 横轴 xticks 标签可以用 LaTeX 命令设置（字符串前加 r）：

```python
plt.plot(X, C, color="blue", linewidth=2.5, linestyle="--", label="cos")
plt.plot(X, S, color="red", linewidth=2.5, linestyle="--", label="sin")
plt.legend(loc='upper left')
plt.xticks([-np.pi, -np.pi/2, 0, np.pi/2, np.pi],
           [r'$-\pi$', r'$-\pi/2$', r'$0$', r'$+\pi/2$', r'$+\pi$'])
plt.yticks([-1, 0, +1], [r'$-1$', r'$0$', r'$+1$'])
plt.show()
```

### spines（坐标轴线）

每幅图有四条 spines（上、下、左、右）。要把 spines 放在图的中间，将其中两条（上和右）设置为无色，然后调整剩下的两条到合适的位置——数据空间的 0 点：

```python
ax = plt.gca()
ax.spines['right'].set_color('none')
ax.spines['top'].set_color('none')
ax.xaxis.set_ticks_position('bottom')
ax.spines['bottom'].set_position(('data', 0))
ax.yaxis.set_ticks_position('left')
ax.spines['left'].set_position(('data', 0))
plt.show()
```

### annotate 注释

使用 `annotate()` 可以在坐标系任何一个位置放置文本：

- `xy`：指定需要进行注释的图形位置；
- `xytext`：指定注释文本的位置；
- 两者都使用 $(x, y)$ 元组数据；
- `arrowprops` 设置箭头属性，`shrink` 参数表示箭头总长度"缩水"的比例。

```python
ax = plt.subplot(111)
t = np.arange(0.0, 5.0, 0.01)
s = np.cos(2 * np.pi * t)
line = plt.plot(t, s, lw=2)
plt.annotate('local max', xy=(2, 1), xytext=(3, 1.5),
             arrowprops=dict(facecolor='black', shrink=0.05))
plt.ylim(-2, 2)
plt.show()
```

复杂例子：在 sin/cos 图中标注 $\sin(2\pi/3)=\sqrt{3}/2$ 与 $\cos(2\pi/3)=-1/2$，用虚线引到坐标轴并画点：

```python
t = 2*np.pi/3
plt.plot([t, t], [0, np.cos(t)], color='blue', linewidth=2.5, linestyle="--")
plt.scatter([t, t], [np.cos(t)], color='blue')
plt.annotate(r'$\sin\left(\frac{2\pi}{3}\right)=\frac{\sqrt{3}}{2}$',
             xy=(t, np.sin(t)), xytext=(1.7, 1.2), fontsize=16,
             arrowprops=dict(arrowstyle="->", connectionstyle="arc3, rad=0.2"))
plt.plot([t, t], [0, np.sin(t)], color='red', linewidth=2.5, linestyle="--")
plt.scatter([t, t], [np.sin(t)], color='red')
plt.annotate(r'$\cos\left(\frac{2\pi}{3}\right)=-\frac{1}{2}$',
             xy=(t, np.cos(t)), xytext=(0.2, -1), fontsize=16,
             arrowprops=dict(arrowstyle="->", connectionstyle="arc3, rad=0.2"))
plt.show()
```

## 柱状图 bar / barh

柱状图由一系列高度不等的条纹或线段表示数据的分布状态，横轴一般表示类型，纵轴表示数量或占比。

| 参数名称 | 说明 |
|---|---|
| `left` | 数组。表示横轴数据 |
| `height` | 数组。表示横轴所代表数据的数量 |
| `width` | 0 到 1 之间的浮点数。指定柱状图宽度 |
| `color` | 特定字符串或颜色字符串数组。柱状图颜色 |

柱状图与散点图/折线图的差别：柱状图的一个数轴是分类变量，另一个数轴是频数；散点图和折线图的两个轴都是数值型数据。

### 水平柱状图 barh

```python
icecream = pd.DataFrame({'Flavor': ['Chocolate', 'Strawberry', 'Vanilla'],
                         'Number of Cartons': [16, 5, 9]})
plt.barh(icecream['Flavor'], icecream['Number of Cartons'])
plt.show()
```

**电影公司数据案例**：`studios`（电影公司名数组）与 `counts`（电影数量数组），先 `sort_values(by='Count', ascending=False)` 排序，再画水平柱状图；也可用 `x_pos = np.arange(len(movies_and_studios.index), 0, -1)` 指定 y 轴位置，`plt.barh(x_pos, counts, height=0.8, left=0, color='y', edgecolor='r', linewidth=2.0)`，用 `plt.yticks(x_pos, studios)` 设置标签，`plt.grid(True)` 加网格。

### 垂直柱状图 bar

函数形式：`bar(left, height, width, bottom, color, align, yerr)`

- 水平柱形图四个顶角位置：left, left+width, bottom, bottom+height；
- `left`：柱形图左边沿在 x 轴的位置序列，一般采用 arange 产生；
- `height`：柱形图沿着 y 轴的高度数值序列；
- `width`：柱子宽度，一般设为 1 即可，默认为 0.8，让柱子之间有空隙；也可以是数组；
- `bottom`：柱形图底边的 Y 坐标；
- `color`：柱形图填充颜色（facecolor），也可以是数组；
- `edgecolor`：柱子边线的颜色；`linewidth`：边线宽度；
- `xerr` / `yerr`：x 或 y 轴柱子上的误差线；`ecolor`：误差线颜色；`capsize`：误差线端帽长度；
- `align`：plt.xticks() 标签的位置，可选 `{'edge', 'center'}`；
- `orientation`：柱子方向，可选 `{'vertical', 'horizontal'}`；
- `log`：布尔值，默认 False，True 时把坐标轴取对数。

```python
plt.figure(1, figsize=(9, 6))
n = 8
X = np.arange(n) + 1
Y1 = np.random.uniform(0.5, 1.0, n)
Y2 = np.random.uniform(0.5, 1.0, n)
plt.bar(X, Y1, width=0.35, facecolor='lightskyblue', edgecolor='white')
plt.bar(X+0.35, Y2, width=0.35, facecolor='yellowgreen', edgecolor='white')
plt.bar(X+0.35, -Y2, width=0.35, facecolor='#ff9999', edgecolor='white')
# 用 plt.text(x, y+0.05, '%.2f' % y, ha='center', va='bottom') 在柱顶加数值
plt.ylim(-1.2, 1.2)
plt.show()
```

注意：水平柱状图 `plt.barh` 中，宽度 width 变成了高度 height。想把一组数据打到下边，只需在数据前使用负号（如 `plt.bar(X, -Y2, ...)`）。

**bottom 用法（堆叠柱状图）**：

```python
plt.rc('font', family='SimHei', size=13)
num = np.array([13325, 9403, 9227, 8651])        # 聊天/支付/团购优惠券/在线视频
ratio = np.array([0.75, 0.76, 0.72, 0.75])
men = num * ratio
women = num * (1 - ratio)
x = ['聊天', '支付', '团购\n优惠券', '在线视频']
width = 0.5
idx = np.arange(len(x))
plt.bar(idx, men, width, color='red', label='男性用户')
plt.bar(idx, women, width, bottom=men, color='green', label='女性用户')
plt.xlabel('应用类别')
plt.ylabel('男女分布')
plt.xticks(idx+width/2, x, rotation=40)
plt.legend()
```

**errorbar 误差线用法**：

```python
N = 5
menMeans = (20, 35, 30, 35, 27)
womenMeans = (25, 32, 34, 20, 25)
menStd = (2, 3, 4, 1, 2)
womenStd = (3, 5, 2, 3, 3)
ind = np.arange(N)
width = 0.35
p1 = plt.bar(ind, menMeans, width, color='#d62728', yerr=menStd)
p2 = plt.bar(ind, womenMeans, width, bottom=menMeans, yerr=womenStd)
plt.ylabel('Scores')
plt.title('Scores by group and gender')
plt.xticks(ind, ('G1', 'G2', 'G3', 'G4', 'G5'))
plt.yticks(np.arange(0, 81, 10))
plt.legend((p1[0], p2[0]), ('Men', 'Women'))
plt.show()
```

（注意：`legend` 的参数必须为元组，如 `legend((line1, line2), ('label1', 'label2'))`。）

## 饼图 pie

饼图将各项大小与总和的比例显示在一张"饼"中，清晰反映部分与部分、部分与整体之间的比例关系。

| 参数名称 | 说明 |
|---|---|
| `x` | 数组。用于绘制饼图的数据 |
| `explode` | 数组。指定项距离饼图圆心为 n 个半径 |
| `labels` | 数组。指定每一项的名称 |
| `color` | 特定字符串或包含颜色字符串的数组。饼图颜色 |
| `autopct` | 特定字符串。指定数值的显示方式 |
| `pctdistance` | 浮点数。比例 autopct 与圆心的距离（按半径比例） |
| `labeldistance` | 浮点数。名称 labels 与圆心的距离 |
| `radius` | 浮点数。饼图的半径 |

```python
df_phone_prop = [0.8482, 0.0428, 0.1089]
plt.pie(df_phone_prop, labels=['yidong', 'dianxin', 'liantong'], autopct='%1.2f%%')
plt.title("phone operator")

```

## 箱线图 boxplot

箱线图也称盒子图，用来刻画数据的分布情况，最早由 John W. Tukey 于 1969 年提出。有两个组成部分："箱"和"线"。

| 参数名称 | 说明 |
|---|---|
| `x` | 数组。用于绘制箱线图的数据 |
| `notch` | 布尔值。中间箱体是否有缺口 |
| `sym` | 特定字符串。指定异常点形状 |
| `vert` | 布尔值。图形纵向或横向 |
| `positions` | 数组。图形位置 |
| `widths` | 数值或数组。每个箱体的宽度 |
| `labels` | 数组。指定每一个箱线图的标签 |
| `meanline` | 布尔值。是否显示均值线 |

```python
from numpy.random import normal
heights = []
N = 10000
for i in range(N):
    while True:
        height = normal(172, 6)
        if 0 < height:
            break
    heights.append(height)

plt.boxplot([heights], labels=['Heights'])
plt.title('Heights Of Male Students')
plt.show()
```

## 概率图 qqplot

概率图用来判断随机样本是否来自某一特定总体（默认是正态总体）。

```python
from statsmodels.graphics.gofplots import qqplot

# 样本1：来自正态分布，均值 2，标准差 1（与标准正态比较时明显偏离 45° 线）
data1 = np.random.normal(loc=2, scale=1.0, size=100)
qqplot(data1, line='45', dist='norm')
plt.show()

# 样本2：来自标准正态分布（散点贴合 45° 线）
data2 = np.random.normal(loc=0, scale=1.0, size=100)
qqplot(data2, line='45', dist='norm')
plt.show()
```
