## Pandas 简介

表格是展示数据集的一种基本方法。本章介绍如何通过 **Pandas** 模块来处理表格。该模块纳入了大量的库、方法和一些标准的数据类型，提供了高效地操作大型数据集所需的工具。

- 最初被作为**金融数据分析工具**而开发，为时间序列分析提供了很好的支持；
- **时间序列数据**：对单个个体连续观测一段时间收集到的数据；
- **Pandas 名称来源**：面板数据分析（Panel Data Analysis）。面板数据指对多个个体在一段时期内进行连续观测得到的数据。同一时间点同时观察多个个体；对每个个体而言会有多次观测。可以简单认为，面板数据是时间序列数据的推广。

Pandas 模块可处理如下四种类型数据：

1. **一维序列 Series**：与 Numpy 的 Array 非常类似。与 List 的区别：List 中的元素可以是不同的数据类型，而 Array 和 Series 中只允许存储相同的数据类型，这样可以更有效地使用内存、提高运算效率；
2. **以时间为索引的 Time-Series**：也是一维序列；
3. **两维表格型数据结构 DataFrame**：可以理解为 Series 的容器，多个 Series 放在一起组成 DataFrame；
4. **三维面板数组结构 Panel**：可以理解为 DataFrame 的容器。

本课程着重介绍 Series 和 DataFrame。Series 产生一维、相同类型数据；DataFrame 产生两维、可以包含不同类型的数据。Series 是 DataFrame 的一种特殊情况。

```python
import numpy as np
import pandas as pd
```

## Series

用 `pd.Series` 创建自带索引（index）的数组：

```python
s = pd.Series([1, 2, np.nan, 4])
```

输出：

```
0    1.0
1    2.0
2    NaN
3    4.0
dtype: float64
```

- 最后一行是 Series 中数据的类型；第二列是数据，第一列是索引 Index；
- 数据与索引可分别取出：

```python
s.values    # array([ 1., 2., nan, 4.])
s.index     # RangeIndex(start=0, stop=4, step=1)
```

默认情况下索引是从 0 开始的一列整数，但创建时可以指定索引（这点和字典类似），索引可以是任何类型的数据（例如字符串）：

```python
s = pd.Series([1, 2, np.nan, 4],
              index = ['A', 'B', 'C', 'D'])
s['A']      # 1.0（通过索引获取对应位置的数据）
```

## DataFrame

DataFrame 非常接近电子表格或 mysql 数据库的形式：竖列称为 columns，横行称为 index。通过 columns 和 index 可以确定某个数据点的位置。

### 创建方式

**方式一：由矩阵创建**

```python
df = pd.DataFrame(np.arange(6).reshape(2, 3))
#       0  1  2
# 0     0  1  2
# 1     3  4  5

df = pd.DataFrame(np.arange(6).reshape(2, 3),
                  index = ['第一行', '第二行'],
                  columns = ['A', 'B', 'C'])
```

**方式二：用字典创建**（常用方法）。字典的"键"就是 columns 值，每个"键"对应的"值"是一个列表，是竖列中的填充数据；不指定 index 时默认从 0 开始的整数：

```python
df = pd.DataFrame({'值班': ["A", "B", "C", "D", "E"],
                   '星期': ["一", "二", "三", "四", "五"]})
```

**方式三：字典套字典**。第一层键规定列名称，第二层字典键规定行索引，第二层字典值规定数据：

```python
data = {'值班': {'first': 'A', 'second': 'B'},
        '星期': {'first': '一', 'second': '二'}}
df = pd.DataFrame(data)
```

通过自定义 index 和 columns 值可修改数据顺序（这是 columns 值和字典键明显的不同）：

```python
df_new = pd.DataFrame(df, index=['second', 'first'], columns=['星期', '值班'])
```

**方式四：用 Series 创建**。每个 Series 将成为一行（注意不是一列）：

```python
duty = pd.Series(['A', 'B', 'C', 'D', 'E'], index=[1,2,3,4,5])
day  = pd.Series(['一', '二', '三', '四', '五'], index=[1,2,3,4,5])
df = pd.DataFrame([duty, day])
#      1  2  3  4  5
# 0    A  B  C  D  E
# 1    一 二 三 四 五
```

当通过索引或列规定了相应位置的数据时，没有规定的位置上的值为空（NaN）：

```python
day = pd.Series(['二', '三', '四', '五'], index=[2,3,4,5])
df = pd.DataFrame([duty, day])
#      1    2    3    4    5
# 0    A    B    C    D    E
# 1   NaN   二   三   四   五
```

**混合类型示例**（综合创建）：

```python
NumRows = 4
df = pd.DataFrame({
    'A': pd.date_range('20191201', periods=NumRows),
    'B': pd.Series(range(NumRows), dtype='float'),
    'C': np.array(3, dtype='int32'),
    'D': pd.Categorical(['测试', '训练', '测试', '训练']),
    'E': 'foo',
    index = list(range(NumRows))
})
```

## 排序操作

```python
df.sort_index(axis=1, ascending=False)   # 按列标签排序（axis=1）或行标签（axis=0），默认升序
df.sort_values(by='B')                   # 按某一列数值排序，默认升序
```

### loc 与 iloc

DataFrame 提供两个操作符访问数据：

- **loc**：通过行和列的**索引（标签）**访问数据；
- **iloc**：通过行和列的**下标**访问数据。

```python
df.loc[0, :]            # 按标签选择指定行（返回 Series）
df.loc[:, ['A', 'B']]   # 按标签选择指定列
df.loc[0:3, ['A', 'B']] # 按标签选择指定的行和列（注意 loc 切片含终点）

df.iloc[3, :]           # 按行下标选择
df.iloc[1:3, 0:2]       # 按行及列的下标选择（iloc 切片不含终点）
df.iloc[[1, 2], [0, 2]] # 按行及列下标列表选择
df.iloc[1:2, :]
df.iloc[:, 1:5]
df.iloc[1, 1]           # 1.0

df.iat[1, 1]            # 与 df.iloc[1,1] 等价，但运行速度更快
```

### 布尔索引

```python
df[df.B > 1]                  # 访问具有指定特征的行
df_sub = df.iloc[0:2, 1:3]
df_sub[df_sub > 0]            # 返回与表格形状相同的 dataframe，符合条件的位置返回原数值，否则为 NaN
df[df['D'].isin(['测试'])]    # 用 isin() 函数进行过滤
```

## 增删改操作

### 增加一列 / 修改指定位置的值

```python
s1 = pd.Series([1, 2, 3, 4], index=[0, 1, 2, 3])
df['F'] = s1                # 增加一列

df.loc[0, 'C'] = 0          # 修改指定位置的值
df.loc[1, "C"] = 0
df.loc[:, 'G'] = np.array([5] * len(df))   # 整列赋值为 5

dfcopy = df.copy()          # 复制表格
dfcopy[dfcopy['C'] > 0]
```

### reindex（自动对齐）

自定义的索引会自动寻找原来的索引，如果是一样的，就取原来索引对应的值，这称为**自动对齐**。`reindex()` 可以改变、增加或者删减一些索引值，并返回一个副本。

```python
df_rd1 = df.reindex(columns=['A', 'D', 'H', 'F'])
# 新索引没有对应值时，值被 NaN 填充

df_rd2 = df.reindex(columns=['A', 'D', 'H', 'F'], fill_value=14)
# 用 fill_value 指定填充值

df_rd3 = df.reindex(columns=['A', 'D', 'H', 'F'], method='ffill')
# method 设置向前填充（'ffill' 或 'pad'）与向后填充（'bfill' 或 'backfill'）
# 向前填充：新索引没有对应数值时取前一个索引的值；向后填充：取后一个索引的值
```

### drop 与 del

`drop` 方法并不实际改变数据框，而是提取被删除数据后剩下的部分；`del` 方法会直接删除数据框中指定的数据。

```python
df.drop([0, 1], inplace=True)         # 删除行（默认 axis=0）
df.drop('G', axis=1, inplace=True)    # 删除列
delCol = [4, 5]
df.drop(df.columns[delCol], axis=1, inplace=True)   # 建议按序号删除多列
```

删除多余的行或列会导致索引不连续，可指定某一列为索引列或重置索引：

```python
df.set_index('A', inplace=True)       # 指定某一列为索引列
df.reset_index(level=[0], inplace=True)  # 重置索引
```

## 案例：拿破仑远征数据（Minard.csv）

1812 年拿破仑进攻俄国。数据保存在 Minard.csv 中（可自行记录保存为 csv 格式）。

```python
minard = pd.read_csv('~/Minard.csv')   # ~ 请指定文件所在的路径
```

数据（8 行 5 列）：longitude（经度）、latitude（纬度）、city（城市）、direction（方向 Advance/Retreat）、survivors（幸存人数，从 145000 递减到 12000）。

```python
len(minard.index)      # 8
len(minard.columns)    # 5
minard.columns         # Index(['longitude','latitude','city','direction','survivors'], dtype='object')

minard.rename(columns={'city': 'city name'}, inplace=True)   # 改列名称

# 提取单列（多种等价方式）
minard['survivors']
minard.loc[:, 'survivors']
minard.iloc[:, 4]
minard.iloc[0, 4]      # 145000
minard.iloc[5, 4]      # 24000

# 列操作：计算存活比例
initial = minard.iloc[0, 4]           # 145000
percent_surviving = minard.iloc[:, 4] / initial
minard['percent surviving'] = percent_surviving

# 添加 % 格式
minard['percent surviving'] = pd.Series(["{0:.2f}%".format(val * 100) for val in minard['percent surviving']])
# 100.00%, 96.55%, 87.66%, 68.97%, 37.93%, 16.55%, 13.79%, 8.28%

minard[['longitude', 'latitude']]     # 提取多列

minard1 = minard.drop(['longitude', 'latitude', 'direction'], axis=1, inplace=False)   # drop 返回副本
del minard['longitude']               # del 直接删除
```

## 案例：人口数据

读入某地人口数据（12 行 5 列）：年龄（合计/1-30岁/31-60岁/60岁以上）、性别（小计/男/女）、A、B、C 三列人口数。

```python
print(pop.shape[0], pop.shape[1], len(pop))   # 12 5 12
pop.columns          # Index(['年龄', '性别', 'A', 'B', 'C'], dtype='object')
pop['性别'].unique()  # array(['小计', '男', '女'], dtype=object)
pop['年龄'].unique()  # array(['合计', '1-30岁', '31-60岁', '60岁以上'], dtype=object)

# 挑选 A 和 B 地区数据
partial_pop = pop[['年龄', '性别', 'A', 'B']]
change = partial_pop['A'] - partial_pop['B']
partial_pop['Change'] = change
partial_pop['Percent Change'] = change / partial_pop['A']
partial_pop['Percent Change'] = pd.Series(["{0:.2f}%".format(val * 100) for val in partial_pop['Percent Change']])
# 例：合计行 Change=-1145787，Percent Change=-270.74%

# 排序
diff_pop = partial_pop.copy()
diff_pop1 = diff_pop.sort_values(by='Change', ascending=False)

# 计算 B 地区性别比例
diff_pop1_B = diff_pop1.drop(['A', 'Change', 'Percent Change'], axis=1)
all_ages = diff_pop1_B[diff_pop1_B['年龄'] == '合计']
all_ages = all_ages.sort_values(by='B', ascending=False)
all_ages = pd.DataFrame(all_ages.values, columns=all_ages.columns)
all_ages['Proportion'] = all_ages['B'] / all_ages.loc[0, 'B']
# 合计 100.00%，男 51.51%，女 48.49%

# 1-30 岁男女比例：男 55.22%，女 44.78%

# 各年龄段女/男比例（B 列）：
females = diff_pop1_B[diff_pop1_B['性别'] == '女']
females = females[females['年龄'] != '合计'].sort_index()
males = diff_pop1_B[diff_pop1_B['性别'] == '男']
males = males[males['年龄'] != '合计'].sort_index()
ratios = np.array(females['B']) / np.array(males['B'])
# 1-30岁 0.811085；31-60岁 0.990343；60岁以上 1.004742
```

结论：从表中数据可以看出，所有年龄段的人口 A 地区都低于 B 地区。
