# 第一问

## 算法 1：卡方独立性检验与蒙特卡洛置换检验

**输入**：某属性列（类型 / 纹饰 / 颜色系）与表面风化列；置换次数 $N_{\mathrm{perm}}=5000$。
**输出**：卡方统计量 $\chi^2$、$P$ 值、是否采用置换检验。

**流程**：
1. 以属性为行、风化状态为列构造列联表，记录观测频数。
2. 计算各格的期望频数（行合计 $\times$ 列合计 $\div$ 总样本数），并求卡方统计量（观测与期望差的平方除以期望，逐格求和，对应论文 $\chi^2=\sum_{\ell=1}^{L}\sum_{c=1}^{2}\frac{(n_{\ell c}-E_{\ell c})^{2}}{E_{\ell c}}$）。
3. 判定近似条件：若所有期望频数均 $\ge$ $5$，采用卡方近似，直接取卡方检验返回的 $P$ 值。
4. 否则改用蒙特卡洛置换检验：
   - 固定属性列不变，用固定随机种子将风化标签随机重排 $5000$ 次；
   - 每次重排后重新构造列联表并计算卡方统计量；
   - 统计重排卡方值 $\ge$ 观测卡方值的次数；
   - $P$ 值 =（该次数 $+1$）$\div$（$5000+1$），分子分母同加 $1$ 避免 $P=0$（对应论文 $P_{\mathrm{perm}}=\frac{\sum_{t=1}^{N_{\mathrm{perm}}}\mathbb{1}\{\chi_{t}^{2}\ge\chi_{\mathrm{obs}}^{2}\}+1}{N_{\mathrm{perm}}+1}$）。
5. 返回统计量、$P$ 值与检验方式标记（卡方近似 / 置换）。
6. 结论判定：$P<0.05$ 记显著相关，否则不显著。

## 算法 2：Mann-Whitney U 检验（风化前后成分差异）

**输入**：文物级主表，按玻璃类型 $\times$ 表面风化分组。
**输出**：每种成分的组均值、$P$ 值、变化方向与显著性。

**流程**：
1. 对高钾、铅钡两类玻璃分别处理：取出风化组与无风化组样本。
2. 对 $14$ 种成分逐一检验：
   - 分别取两组的有效检出值（剔除缺失）；
   - 任一组有效样本数 < $2$ 则跳过该成分（样本不足不做检验）；
   - 将两组观测合并排序取秩，计算风化组的秩和，进而得到 $U$ 统计量（对应论文 $U=n_{0}n_{1}+\frac{n_{1}(n_{1}+1)}{2}-R_{1}$）；
   - 用双尾检验求 $P$ 值（小样本精确分布 / 大样本正态近似由库自动处理）；
   - 计算两组均值并标记变化方向（风化组均值更大记上升，否则下降）；
   - $P<0.05$ 记显著。
3. 汇总所有检验结果；再按论文表 5.2 口径挑出高钾（$\mathrm{SiO_2}$/$\mathrm{K_2O}$/$\mathrm{CaO}$/$\mathrm{Al_2O_3}$/$\mathrm{Fe_2O_3}$）与铅钡（$\mathrm{SiO_2}$/$\mathrm{PbO}$/$\mathrm{CaO}$/$\mathrm{P_2O_5}$）的论文关注成分，$P$ 值小于 $0.001$ 的显示为「<$0.001$」。

# 第二问

## 算法 3：K-means++ 聚类与类数选择

**输入**：某类玻璃样本的核心 $7$ 成分标准化值；最大候选类数 $8$。
**输出**：$K=2\sim8$ 的 SSE 与轮廓系数、推荐 $K$ 及推荐方式（轮廓系数 / 肘部法）。

**流程**：
1. 对 $K=2,3,\dots,\min(8,n)$ 逐一执行：
   - 用 K-means++ 初始化质心（$10$ 次重启取最优），迭代「样本分到最近质心 → 簇均值更新质心」直至收敛；
   - 记录簇内离差平方和 SSE 与平均轮廓系数（每个样本：与同簇平均距离 $\alpha_{i}$、与最近异簇平均距离 $\beta_{i}$，轮廓系数 $q_{i}=\frac{\beta_{i}-\alpha_{i}}{\max(\alpha_{i},\beta_{i})}$，全体取平均）。
2. 类数推荐规则：
   - 若最大轮廓系数 $\ge$ $0.05$ 且轮廓系数序列不单调递减 → 取轮廓系数最大的 $K$（优先依据）；
   - 否则退化为肘部法：计算 SSE 相邻下降的相对幅度，取相对下降最大处之后的 $K$。
3. 在评估表上标记推荐 $K$。

# 第三问

## 算法 4：假设-验证风化前成分还原

**输入**：某未知样本观测成分、假设类别（高钾或铅钡）、对应类型的风化还原模型。
**输出**：还原后的风化前成分向量；若假设不可行则返回「不可行」。

**流程**：
1. 可行性检查 1：该假设类型的关键成分子集必须全部检出且非 $0$，否则假设不可行。
2. 用假设类型的风化程度（高钾 $0.8$、铅钡 $0.75$）与反推分母计算 $\mathrm{SiO_2}$ 变化量：$\Delta_{\mathrm{SiO_2}}=$ 假设风化程度 $\div$ 反推分母。
3. 逐成分还原：预测风化前 $=$ 观测含量 $-$ 反应比例 $\times$ $\Delta_{\mathrm{SiO_2}}$；反应比例缺失的成分保留原观测值，观测缺失的成分置 $0$。
4. 可行性检查 2（物理范围）：任一分量小于 $-0.5$、大于 $100.5$，或总和大于 $105$，则还原结果超出成分含量物理范围，假设不可行。
5. 返回还原向量或「不可行」。
